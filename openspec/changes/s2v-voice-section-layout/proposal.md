# 声音区子分区布局 + 折叠区默认收缩（s2v-voice-section-layout）

## Why

用户真实反馈（2026-10-18，附截图 `局部截取_20261018_200059.png`）：视频创作-故事讲述流水线详情页
「声音」折叠区的选项布局乱，明确提出三点调整 + 两点统一要求：

1. 「语音生成器」和「语音 / 音色 ID」单独为一行；
2. 「背景音乐」和「背景音乐音量」单独为一行；
3. 「音色复制 / 克隆」的区域占满整个宽度（当时与「背景音乐音量」并排，只占半行宽）；
4. 这三个区域要从 UE 角度考虑，**从视觉上分开**；
5. 其他选项区域一起统一优化；
6. 所有参数选项区域，除了「基础」区域，其他都应该默认收缩状态。

### 根因溯源（QM-5 ①）

`.config-span-2` 的实现是 `grid-column: span 2`，而它所在的 `.s2v-field-grid` 是
`repeat(auto-fit, minmax(min(280px, 100%), 1fr))`——**列数由容器宽度决定**。
于是 `span 2` 在 2 列时是满宽、3 列时是 2/3、4 列时是半行宽。
用户看到的正是 4 列那一格。**用列数相关的量表达列数无关的意图，是该缺陷的第一性根因。**

次要根因：声音区四类控件平铺在同一个扁平栅格里，没有二级容器；栅格分列是纯几何行为，
不反映语义，于是语义无关的「背景音乐音量」与「音色复制 / 克隆」被排到同一行。

### 逃逸链（QM-5 ②）

| 层级 | 为什么没拦住 |
|------|-------------|
| 单元测试 | `S2vConfigPanels.test.js` 只断言「控件在哪个折叠区」（BGM 归位，2026-10-17），没有任何断言涉及控件在栅格里的排列或子分区结构 |
| 视觉回归 | `create-story2video-detail` 走默认收缩路径，「声音」区控件根本不渲染 ⇒ 像素基线对展开态完全失明 |
| 代码审查 | `.config-span-2` 自 2026-08-09 防撑宽修复引入，审查焦点在「长内容不溢出」，未追问「满宽语义是否依赖列数」 |

`span 2` 自引入起就带着这个隐含前提，只是此前容器宽度恰好排 2 列，缺陷未暴露。

## What Changes

1. **声音区内建三个子分区**（纯渲染层，`S2vConfigPanels.vue`）
   - `s2v-subgroup-voiceNarration`（旁白设置）：语音生成器、语音模型、语音 / 音色 ID；
   - `s2v-subgroup-voiceBgm`（背景音乐）：背景音乐下拉 + 管理按钮 + 历史路径状态 + 背景音乐音量；
   - `s2v-subgroup-voiceClone`（音色复制 / 克隆）：克隆面板 / 个人音色槽位说明 / 未接入克隆能力提示。
   - 每个子分区内部各有一个独立的 `.s2v-field-grid`，子分区之间不得共享栅格。
   - `optionKey` / `data-testid` / 持久化字段 / IPC 全部不变。

2. **子分区卡片视觉样式**（`create-view.css`）
   - `.s2v-subgroup` 增加 `background` + `border` + `border-radius` + `padding`，
     与折叠区外壳形成「外壳 → 卡片」两级层次；`.s2v-subgroup-title` 微调间距；
     卡片内栅格去掉自身左右 padding（避免双重内缩）；窄屏收紧。
   - 「高级」区既有 `splitTiming` / `templateOutput` 两个子分区共用同一类名，**一并获得卡片样式**
     （用户明确要求「其他选项区域一起统一优化」）。

3. **折叠区默认收缩显式化**（`CreateView.vue`）
   - `s2vOpenSections` 默认仅 `basic` 展开（写入注释声明意图）；
   - 快照恢复（`restoreS2VLastOptions` / `applyS2VConfigProfile`）改为「先显式复位到默认态，
     再只打开快照列出的分组」，消除对 data() 默认值恰好全关的隐含依赖。

4. **locale 成对新增 3 键**（zh/en）
   - `create.story2video.subgroups.voiceNarration` / `voiceBgm` / `voiceClone`；
   - `CreateView.s2vSubgroupLabel` 的 fallback / english 映射表同步补三条。

## Impact

- **受影响**：故事讲述流水线详情页「声音」与「高级」折叠区的外观、折叠区默认态与恢复逻辑。
- **不受影响**（已核验）：主进程 / preload / IPC / 数据库零改动；`s2vConfig` schema 与
  持久化 payload 零改动；运营后台 optionKey 目录无新增；像素基线默认收缩态逐字节不变
  （未更新任何基线文件）。
- **连带外观变化**：「高级」区两个子分组从「虚线标题」升级为卡片。这是统一优化的预期结果，
  已作为残留风险登记（用户可要求拆分类名）。
