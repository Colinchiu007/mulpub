# 提案：把「阻断必须落到退出码」从结构锁升级成行为锁（给 CLI 一个 `--root` 注入点）

## Why

`scripts/check-gate-record-debt.js` 的 `main()` 里那一行 `if (hasBlocking(r, …)) process.exit(1)` 是整条账本判据**唯一的拦截出口**——`collect()` 返回值再真，只要这行断了，CI 就照收。

现在看着它的只有一道**结构锁**：读源码、剥注释、正则匹配那一行还在不在。结构锁能防"有人把映射删掉"，防不了"映射在、但因为变量作用域/早退分支/异常路径而永不执行"。

本 change 的动因是**一条我自己写错、被外部评审当场否证的边界**。PR #4001 的执行记录里我写下：

> `main()` 的 root 取 `path.resolve(__dirname, '..')`、无 `--root` 注入点 ⇒ 造不出"夹具里确有阻断"的行为态；补成行为锁须人工过目。

前半句（无注入点）成立，**后半句被本仓自己的代码否证**：`scripts/check-gate-record-debt.test.js` 里那条 `端到端：真历史上一笔回填 PR 必须让 CLI 判红并点名那篇记录` 早就 spawn 真 CLI（经 `--base-ref` / `--head-ref`）并断言 `rc === 1`。两次变异（把映射包进块注释、把它挪进 `main()` 外的诱饵函数）里它都与结构锁一起**指名变红** ⇒ 「没有任何东西在看这个出口」是假的。

所以这一刀**不是**在补一个空缺，而是在消掉一个**不存在的约束被写成了边界**：`--root` 唯一还买得到的东西，是"用夹具而不是用一条固定历史提交"来证明阻断——它让这条判据的**新增欠账形态**（未登记 / 重复标题 / 冻结基线漂移）也能被行为级跑一次，而不是只有"人工改写"那一格有端到端覆盖。

**授权来源**：2026-10-20 用户在收尾汇报上明示「第 2、3 条授权你改判据」，本 change 即其中第 3 条。改判据本体属"谁来守门"，无此授权不动。

## What Changes

- `scripts/check-gate-record-debt.js`：`main()` 的取证根从写死的 `path.resolve(__dirname, '..')` 改为**默认可覆盖**——新增 `--root=<路径>`。
  - 不给时**逐字节保持现状**（仍取仓库根）：生产与 CI 行为零变化，这是本刀的第一约束。
  - 给了时，账本、冻结基线、`buildLedger` 的 git 取证 cwd、`buildClosureDiff` 的 git 取证 cwd **必须一起切到该根**——只切一半会造出"夹具内容 + 真仓 git 证据"的混合态，那是新的假绿通道，比没这个旗标更坏。
  - 裸旗标 `--root`（无 `=`值）与未知拼写必须**抛错**，落进既有的"判据自身故障"档；不得静默回落默认根（同一函数里 `--carrier-mode` 已有先例与教训注释）。
- `scripts/check-gate-record-debt.test.js`：新增行为用例——建一个"载体有未收口行、账本没登记"的夹具根，spawn 真 CLI 带 `--root=<夹具>`，断言 `rc === 1` 且输出点名那条记录。
- 既有结构锁**保留不删**：它测"映射还在不在"，新用例测"真造出阻断时真会拦"，两件事不能互相替代（本仓把"用一条锁冒充另一条"记为装饰性门禁的常见落点）。
- 执行记录里那条被否证的边界说明已在 #4001 第二笔提交中改写；本 change 把它引用的技术前提（无注入点）一并消掉，不留"看起来还欠着"的描述。

## Impact

- Affected specs: `quality-gate-execution-record`（新增一条 Requirement）
- Affected code: `scripts/check-gate-record-debt.js`、`scripts/check-gate-record-debt.test.js`
- 运行行为：**对已推送的 CI 与本机默认用法零影响**（不给 `--root` 时代码路径与今天逐字相同）；被改的是"能不能测它"。
- 风险与回滚：新增旗标若实现有误会**只在被显式传入时**生效；回滚 = revert 本 PR 即可，无数据迁移、无持久化态。
- 不在本刀做的（明确划界）：`--carrier-mode` / `--base-ref` / `--head-ref` 的语义一概不动；`collect()` 的注入契约不动；判据的阈值与词表不动。
