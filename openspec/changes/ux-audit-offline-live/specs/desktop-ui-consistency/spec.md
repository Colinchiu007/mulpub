## ADDED Requirements

### Requirement: 网络连通性变化必须即时反映到离线横幅，且只有一个最终裁决方

用户在会话中途失去或恢复网络连接时，应用必须在**同一次事件循环内**给出可见反馈，
不得等到重启或下一次轮询。连通性的最终结论以主进程为准（它持有网络栈状态与待发布队列深度）；
渲染层的事件只负责第一响应，事件后必须向主进程复核，复核结论覆盖事件值。

#### Scenario: 中途断网

- **WHEN** 应用已启动、用户此刻断网（浏览器派发 offline 事件）
- **THEN** 离线横幅立即出现，不等任何 IPC 往返完成

#### Scenario: 中途恢复

- **WHEN** 网络恢复（浏览器派发 online 事件）
- **THEN** 横幅立即消失，随后由主进程复核结果决定是否再次出现

#### Scenario: 两边结论不一致时不各写各的

- **WHEN** 浏览器认为已在线，而主进程的网络栈仍判离线（例如代理失效、DNS 不通）
- **THEN** 复核结果落地后横幅保持显示「离线」，不得被浏览器事件的值覆盖回去

#### Scenario: 待发布队列深度只认真源

- **WHEN** 任一连通性事件触发复核
- **THEN** 横幅上的待发布数量取主进程返回的计数，不由渲染层自行推算

#### Scenario: 复核失败不得伪装成「在线且无积压」

- **WHEN** 复核调用失败或返回非成功码
- **THEN** 保留事件给出的连通性，并留下可检索的告警日志；不得静默回落成默认值

#### Scenario: 离开页面后不留活监听

- **WHEN** 承载横幅的组件被卸载
- **THEN** 事件监听器与主进程订阅被成对解绑，后续全局事件不得再改变该已卸载实例的状态

### Requirement: 离线横幅的文案、颜色与播报必须对全部用户可用

横幅的所有用户可见文字必须来自语言资源并 zh/en 成对；颜色必须走设计令牌且在暗色档下显式声明；
横幅本身必须是可播报的状态区域；装饰图标不得进入可访问名；入场动画必须尊重系统的减弱动效设置。

#### Scenario: 语言切换后文案随语言变化

- **WHEN** 应用语言由中文切到英文且此刻处于离线
- **THEN** 横幅显示英文文案，且不残留中文

#### Scenario: 暗色档不是亮色补丁

- **WHEN** 应用在暗色档显示离线横幅
- **THEN** 底色与文字色取自暗色档显式声明的令牌，文字与底色对比度满足 AA

#### Scenario: 读屏能被告知

- **WHEN** 横幅出现或消失
- **THEN** 该区域以可读屏状态区域语义暴露（status + polite），装饰图标本身不被朗读

#### Scenario: 无待发布任务时不虚报数量

- **WHEN** 待发布计数为 0
- **THEN** 横幅只显示离线说明，不显示「0 个待发布」这类无信息量的计数

### Requirement: 状态播报锚点必须常驻，断网与恢复两侧都可被播报

离线状态的可播报区域 MUST 是一个**常驻**容器（`role="status"` + `aria-live="polite"`），
断网与恢复 MUST 都表现为该容器内的文本变化；MUST NOT 把播报属性挂在被条件渲染
（`v-if`）整体插入/移除的节点上 —— `role=status` 的播报语义依赖常驻 region，
节点被移除时"已恢复"这半边对读屏用户不存在。

#### Scenario: 区域从不被移除

- **WHEN** 状态在离线与在线之间往返
- **THEN** `data-testid="offline-live"` 容器始终存在于 DOM，`role`/`aria-live` 挂在它身上
- **AND** 横幅（`offline-banner`）只是其内容，在线时不存在

#### Scenario: 恢复给出一次性回执而不是永久横幅

- **WHEN** 状态从离线跃迁为在线
- **THEN** 常驻区域内出现「已恢复连接」（`offlineRecovered`，zh/en 成对）
- **AND** `RECOVERY_NOTICE_MS` 后自动消失，区域文本回到空
- **AND** 首次挂载即为在线时不显示（那不是"恢复"）；显示期间再次断网则立即让位给横幅

#### Scenario: 退回挂在条件节点上会当场变红

- **WHEN** `role="status"` / `aria-live` 被移回横幅行，或容器行加上 `v-if`
- **THEN** 结构锁判红（扫描域排除注释行，避免说明文字自指）
