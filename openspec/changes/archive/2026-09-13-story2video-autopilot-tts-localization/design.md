## Context

需求基线（.ccg/tasks/story2video-autopilot-tts-localization/requirements.md）已确认 8 项范围：流水线更名与 i18n、自动连续执行、参数收敛、风格语义去重、TTS 音色管理、图片失败重试、文档补充、UE 优化建议。任务标注 L/high，处于 analysis 阶段。本 design 把已确认的分析结论固化为实现层设计。

## Goals / Non-Goals

**Goals:**
- 自动流水线：参数提交后连续执行，进度以阶段清单呈现
- i18n：中英文文案全部由资源文件驱动，无硬编码
- 参数收敛：音调/并发/创意强度隐藏（默认或后台配置），分句语言默认自动识别
- TTS 音色：按模型绑定内置音色 + 个人槽位 + 复制 + 能力约束持久化
- 图片失败：拒绝类失败受控重试（≤5 次），末次给出可操作提示
- 文档：PRD/项目文档随实现同步更新；UE 优化建议独立交付

**Non-Goals:**
- 不臆造用户清单第 11 项（待确认，不阻塞）
- 不假设运营后台路径/配置项——必须从本机历史与代码确认
- 不实施 UE 优化建议中的额外信息架构调整（待用户确认）
- 不改变 TTS 供应商官方契约（内置音色、克隆方式、文件限制、API 模型以官方文档为准）

## Decisions

**D1: 流水线执行模型 — 参数提交后自动连续执行**
- 现状为引导式分步；改为一次提交启动、后台阶段推进
- 进度呈现：阶段清单（每阶段状态：pending/running/done/failed），替代单进度条
- 提交按钮文案："启动流水线"

**D2: i18n — 资源驱动**
- 新增 i18n 资源（zh/en），所有用户可见文案走资源键
- 流水线名称展示为"图片轮播"（本地化后）

**D3: 参数收敛**
- 音调、并发数、创意强度：从界面隐藏，使用默认值或运营后台配置（配置项从代码确认）
- 分句语言默认"自动识别"

**D4: 图片风格与提示词风格语义关系**
- 明确两者语义：图片风格描述画面呈现，提示词风格约束文本生成风格
- 相同语义去重，不同语义保留，配置持久化

**D5: TTS 音色管理 — 按模型绑定**
- 内置音色：按 TTS 模型枚举，随模型能力表持久化（官方文档为准）
- 个人槽位：用户保存的音色，绑定来源模型；复制能力：从内置/个人音色复制到个人槽位
- 约束持久化：模型能力（克隆支持、文件限制、API 模型名）结构化存储

**D6: 图片失败重试 — 受控循环**
- 拒绝类失败：提示词风险分析（哪些词/风格触发）→ 重写 → 重试，最多 5 次
- 第 5 次仍失败：输出可操作提示（具体到可调整的提示词维度）

## Risks / Trade-offs

- [运营后台配置假设风险] → 配置项必须从本机历史/代码确认后才实现；未确认前用默认值
- [TTS 供应商契约漂移] → 内置音色/克隆方式以官方文档为唯一依据，能力表可配置而非硬编码
- [i18n 遗漏硬编码文案] → 视觉回归 + 中英双语言切换用例覆盖
- [UE 优化范围蔓延] → 独立 change/建议文档，不进入本轮实现
- [第五次失败无解] → 可操作提示而非无限重试，明确给用户下一步动作
