## ADDED Requirements

### Requirement: 审查模式判定的取证面不得包含判定器自身产物

`scripts/ccg-review-decider.js` 决定一次改动需要几路外部审查（`mode ∈ skip|single|dual`），并把结论落进 `.ccg/reviews/` 下的 JSON 产物；该产物会随同一个提交进入 git，且其正文逐字复述方案、执行记录与上一次判定理由。系统 SHALL 把 `.ccg/` 目录下的文件从审查模式判定的**取证面**排除，且排除必须同时对「变更规模」与「敏感内容命中」两维生效，使验证层的两条采集路径（暂存区档、已提交区间档）对同一份改动判出**同一个** `mode`。被排除文件内出现的敏感内容命中 SHALL 单独计数并在判定输出中点名，**只报告、不改判定**，不得静默丢弃。

判定器自身的产物、以及下游 `scripts/check-pr-exec-record.js` 读到的深度审查欠账条数，都以此取证面为唯一来源；本 Requirement 不适用于 `stagedDiffHash` / `recordFileName()` 的内容寻址配方（那里已有独立的 `.ccg` 排除并由 `scripts/deep-review-deps.test.js` 锁定）。

#### Scenario: 只含判定器产物的提交不得被自身散文顶成 dual

- **WHEN** 一次提交只改动 `.ccg/reviews/<sha>.json`，且产物正文里含有敏感词表命中的散文（例如「授权」「密钥」出现在方案复述中）
- **THEN** 该改动经已提交区间档判定的 `changedLines` 代码规模不得计入这些行，`mode` 不得因这些命中被置为 `dual`
- **AND** 判定输出必须打印这些文件里的命中条数（report-only 计数），且**行为锁必须真跑一次 CLI 并断言该数出现在 stdout 且与 `judge()` 的 stats 读数相等**——"字段存在"不等于"这行真会被打印"
- **AND** 该计数不得升级为阻断判据：产物里的命中逐字来自方案与执行记录正文，同一份散文一处不消费、另一处拦下来是自相矛盾

#### Scenario: 两条采集路径必须同判且同观测

- **WHEN** 同一份工作树改动分别经「验证层·暂存区」与「验证层·已提交区间」两条采集路径判定
- **THEN** 两次判定的 `mode` 必须相等，且 `ccgSensitiveContentHits` 读数也必须相等（只对齐 `mode` 而对不齐观测点，等于把排除做成只在一档存在）
- **AND** 该一致性必须由**单一实现**持有：两条路径都不得在 git 参数层预先摘掉 `.ccg`（预摘会让 JS 层收不到这些行、计数恒为 0）
- **AND** 若两档分歧，必须能由判据自己打印的 `changedLines` / `sensitiveContentHits` 两栏读数指出差异来自哪一维

#### Scenario: 同判锁不得单独成立（必须有绝对参考）

- **WHEN** 夹具同时含一份 `.ccg/` 产物（正文有敏感词散文）与一份真实源码文件（新增行含 `apiSecret = "x"`）
- **THEN** 两条采集路径**各自**都必须判为 `dual` 且 `sensitiveContentHits > 0`
- **AND** 只断"两档相等"不构成回归锁——谓词退化成一恒为真的形态时两档会一起落到同一个错误值，相等断言照样通过

#### Scenario: 只含判定器产物的提交判为 skip

- **WHEN** 一次提交除 `.ccg/**` 外不含任何文件
- **THEN** 两条采集路径都必须判为 `skip`，且代码规模 `changedLines` 为 0
- **AND** 不得出现一档 `skip`、另一档 `single`（那是把口径分裂从"判定过严"换成"判定归属不明"）

#### Scenario: 排除动作不得把敏感判定整条关掉

- **WHEN** 一次改动在**真实源码文件**（非 `.ccg/` 下）的新增行里出现敏感内容命中（例如 `apiSecret = …`）
- **THEN** 判定必须仍为 `dual`，且 `sensitiveContentHits` 必须大于 0
- **AND** 该用例与「产物排除」用例的失败集必须互不相同，以免一条退化同时通过两把锁

#### Scenario: 自身产物谓词必须是单一出处

- **WHEN** 判定规模或分流变更行时需要判断"这个文件是不是判定器自己写的"
- **THEN** 两处必须调用同一个谓词实现，不得各抄一份路径正则
- **AND** 谓词按**路径**判定（`.ccg/` 目录之下），不得按扩展名或"文件名像不像产物"判定

#### Scenario: 决策层的方案正文不在本约束范围内

- **WHEN** 决策层（`layer=plan`）从方案文档正文抽取"路径样 token"并跑敏感路径规则
- **THEN** 本 Requirement 不改变其判定；方案正文点名待改文件仍按既有 `plannedPathHits` 口径处理
- **AND** 该口径的实测发生率必须与判定面改动一并留数，不得以"没出问题"为理由转成默认信任
