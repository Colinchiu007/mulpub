# Design: subtitle-word-integrity

## 2. 两条正交修法

### 2.1 `unit_guard`（确定性规则，非枚举）

数字与量词/单位之间不设切点。取**确定性规则**而非继续扩 `pairs` 枚举：数字单位是封闭集合（`纳米/度/米/秒/元/亿/万/%…`），任何文案里 `8│米` 都是坏切，不存在"这个语境下可以"的例外——这正是规范里"用确定性规则替代逐例枚举"的适用面。

**规则表 schema**（`word_split.unit_guard`）：

```json
{
  "units": ["%", "％", "纳米", "亿元", "亿", "万元", "万", "元", "米每秒", "公里", "千米", "米", "度", "秒", "吨", "克", "升", "瓦", "千瓦", "兆瓦", "赫兹", "像素", "帧", "GB", "MB", "KB", "TB", "个", "台", "辆", "架", "艘", "层", "年", "月", "日", "时", "分"],
  "left_bind_max_digits": 4,
  "min_head_relax": 2
}
```

- `units` 按**最长优先**匹配；含 `%`（半/全角）。
- **left_bind**：切点 `i` 左边是**数字串**（字符集 = ASCII `0-9` + `.` + 中文数词 `一二三四五六七八九十百千万亿兆两零〇` + 全角点）、右边以 `units` 某项开头 ⇒ 拒绝。覆盖 `8│米`、`3.2│亿元`、`一百五十│元`（评审 i1：中文数词与阿拉伯数字在字幕里同形同责，向量 +1 条压力例）。
- **right_bind（单一算法，评审 i3）**：从切点向左跳过空白与标点（中英全半角），取第一个非空白字符 c；当且仅当 c ∈ 引导字符集 `是约到达了超足低高等` 且 c 与右侧数字之间不隔其它汉字 ⇒ 拒绝。反例：`的股票│3 元` c=票 ∉ 引导集 ⇒ 不触发（由 left_bind/邻域重找兜底）；`大约│55%` c=约 ✓；`他说了│60%` c=了 ✓。覆盖 `提升了│60%`、`制程是│3 纳米`、`初期只有大约│55%`。
- `min_head_relax: 2`：right_bind 拒绝后允许头块缩到 `min-2` 重找（沿用 v1.3 的短语边界放宽语义，避免"为了不拆数字而把块切得只剩 2 字"）。

### 2.2 `no_cut_bigrams` 扩充（+7，逐条带实测出处）

`当成`（A 例 `风波当│成`）、`万人`（G 例 `千│万人`）、`遗忘`（G 例 `遗│忘`）、`那段`（G 例 `仿佛那│段`）、`仿佛`（E 例）、`亿元`（F 例，另有 unit_guard 双保险）、`纳米`（B 例，同双保险）。语义与既有条目完全一致（切点不得落在短语内部），实现零改动——只是数据。

**准入即实测（评审 i2）**：每条必须列实测出处，无出处不入——`测试/恐慌/看不见` 无实测实例，**不入本次**（记 §6 待补录）。**`飘地` 被零误伤预检否决**（见 §4.1）：它命中既有 v1.3 向量 `qing_piao_piao` 的块2|3 接缝（会改变已发布期望输出），且该处已有 phrase_boundary 左语境 `轻飘飘` 在管，不重复登记。

**双字对的误伤面评估**：`当│成`被拒后 `findSafeCutPosition` 会在 `[1,max]` 邻域重找（既有机制），`很多人把这场风波当成一次…` 会左移到"把"后（好切点），实测验证。`那段`/`仿佛` 同理。

## 3. 接入点：统一守卫，两处对称

**TS**：`SubtitleSegmenter.isSafeCutPosition` 增加第 5 条 `if (this.isUnitInterior(text, i)) return false;`
**Python**：`_is_safe_cut_position` 增加同款 `if cls._is_unit_interior(text, i): return False`

`isUnitInterior(text, i)` 两端同构：

```text
left = text.slice(max(0,i-8), i)   # 左窗 8 字
right = text.slice(i, i+8)         # 右窗 8 字
if left 尾部是数字串(含.) && right 以 units 某项开头 → true   # left_bind
if left 尾部匹配 引导词+空格?+数字串(含.%) && …
   实际简化：left 以"非数字"结尾 && right 以数字开头 &&
   left 中距 i 最近的字符是 引导集合 之一 → true              # right_bind
```

right_bind 的引导集合取**字符级**（`是约到达了超足` + `提 升 下 降 超 过 不 足` 的尾字），不做成短语枚举——`提升了` 的尾字是 `了`，`下降了` 尾字 `了`，`大约` 尾字 `约`，字符级判定天然覆盖。

**为什么不动 `findSafeCutPosition` 本体**：它已经是"邻近重找"机制，守卫拒绝坏点后它会自动移位——唯一要保证的是**守卫只拒"确定性坏点"**，否则重找会漂移。`unit_guard` 的两类判定都是确定性坏点，符合准入。
