# 决策层评审回应：subtitle-word-integrity（critique-v2 逐条裁决）

> 对抗评审轮 2 判定 `regressed`（1 Critical 未解决）。以下逐条回应，每条给「采纳 / 有证据拒绝」与落地位置。
> 采纳项已写回 `design-subtitle-word-integrity.md`（v3）。

## i1（Critical · completeness）—— **采纳（方案 A：扩数字判定，并同步实测）**

中文数词与阿拉伯数字在字幕里同形同责（`一百元` 被 `一百│元` 劈开与 `100│元` 同样坏）。采纳建议的前半：数字判定扩为 **ASCII 数字 ∪ 中文数词字符集**（`一二三四五六七八九十百千万亿兆两零〇` + `．`全角点）。
同时不假装完备：`三百二十一│元` 这类**多位中文数词**的"数字串"扫描与 ASCII 同构（向前吞数词字符），向量里加一条 `一百五十│元` 压力例。落地：design §2.1 数字字符集定义 + §5 向量 +1。

## i2（Warning · consistency）—— **采纳（如实降级 + 补证据）**

评审指出的自相矛盾成立：我把"准入要有实测误伤"写进了标准，却给 `测试/恐慌/飘地/看不见` 四个词没有任何实测实例。处理：
- **保留并给证据**：`当成`（A 例实测）、`遗忘`（G 例）、`那段`（G 例）、`万人`（G 例 `千│万人`）、`飘地`（上一轮用户文案 `轻飘飘│地用`）、`亿元`（F 例 `3.2│亿元`，另有 unit_guard 双保险）、`纳米`（B 例 `3 纳米`，同双保险）——7 条有实例。
- **降级为待补录**：`测试`、`恐慌`、`看不见` 三条**从本次提交移除**，在 design §6 记"等真实语料命中再录"，不预设。
- 准入条款改为与行为一致："每条新词条必须列实测出处，无出处不入"。

## i3（Warning · clarity）—— **采纳（单一规则）**

采纳：right_bind 的引导字判定统一为**单一算法**——"从切点向左跳过空格/标点/全角标点，取第一个非空白字符 c；c ∈ 引导字符集（`是约到达了超足低高等`，且要求 c 与数字之间**不得隔着汉字**）"。同时给两条精确定义的反例（`大约│55%` c=约 ✓；`他说了│60%` c=了 ✓；`的股票│3 元` c=票 ∉ 引导集 ⇒ 不触发，由 left_bind 或重找兜底）。TS/Python 按同一伪码实现。

## i4（Info · consistency）—— **采纳（职责分离注释，保留双登记）**

`亿元`/`纳米` 保留在两处，但职责注释写明：units 管"数字│单位接缝"（无数字不触发），no_cut_bigrams 管"短语内部任意位置"（`亿│元` 即使前面不是数字也拒绝）。双登记是**纵深防御**（数字守卫被绕过时短语兜底），不是冗余；在规则表 description 里写明这层关系，避免未来维护者删错一边。
