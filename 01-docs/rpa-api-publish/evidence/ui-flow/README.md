# 主链路前端流程活体可视化验证（热门选题 → 一键生成视频 → 故事讲述流水线）

> 日期：2026-09-23 · 环境：`mp-app-live2`（已同步 origin/main `a49531d203`，bilibili=api）
> 手段：CDP over WebSocket 驱动活体 Electron 渲染进程（vite 5231 / cdp 9279），
> `Input.dispatchMouseEvent` 真实点击 + `Page.captureScreenshot` 截图 + `Runtime.evaluate` 读 DOM。

## 1. 验证目标

原始 objective 的前端一寸：在「热门选题」页点【生成视频】→ 一键生成视频 → 自动调用改写引擎
→ 自动进入**故事讲述流水线**（默认选项）。此前仅以旁挂脚本证明后端发布链，本轮补齐**前端交互
流程的活体可视化证据**（截图 + 阶段推进读数），坐实「点击即自动跑流水线」不是静态占位。

## 2. 证据链

### 2.1 热门选题页渲染（`hot-topics-page.png`）

- 路由 `#/hot-topics`（`HotTopics.vue`）。经 native 点击「首页」tab 从被 Bilibili 创作者中心
  BrowserView 覆盖的状态切回 Vue 页面。
- 页面要素：标题「热门选题」+ 副标题「多渠道热门选题聚合，一键创作文案或批量发布」；
  tab 热门选题/收藏选题；分类过滤（全部/综合230/社会16/财经49/科技27/娱乐49/体育12/情感3/
  教育7/健康9/国际27）；全选/已选 N 条/结合爆款库/创作文案/一键发布；10+ 条实时热榜
  （今日秋分、闲鱼公布调查结果、文化中国行秋分节气、年轻人开始花钱找"替身"、中国U23男足vs
  阿联酋U23、中秋国庆调休…），**每行均带【生成视频】按钮**。

### 2.2 点击【生成视频】→ 弹窗启动（`gen-video-modal-start.png`）

- native 点击第一条【生成视频】，弹出「一键生成视频 · <选题标题>」对话框。
- 提示文字：**「已开始生成视频，改写文案后将自动启动故事讲述流水线」**，进度 0% / 已用时 0 秒。
- 阶段列表（等待启动）：文案改写(运行中) → 文案拆分 → 内容增强·场景上下文 → 提示词优化 →
  AI视频场景选择 → 图片/视频/旁白生成。

### 2.3 流水线动态推进（`gen-video-pipeline-43pct.png`）

同一弹窗，两次 `Runtime.evaluate` 读数 + 截图证明**阶段真实推进**（非卡 0%）：

| 读数时刻 | 总进度 | 文案改写 | 文案拆分 | 内容增强 | 提示词优化 |
|----------|--------|----------|----------|----------|------------|
| 第 1 次 | 42%（2分3秒） | ✓ 完成(17秒) | ✓ 拆分为 35 个场景(3秒) | ✓ 已整理 35 个场景故事背景(0秒) | ⟳ 第 **26**/35 场景 |
| 第 2 次（截图） | 43%（3分33秒） | ✓ 完成于 18:09:45 | ✓ 35 个场景 | ✓ 35 个场景 | ⟳ 第 **31**/35 场景 |

- 提示词优化计数 26/35 → 31/35、总进度 42%→43%，证明流水线在**自主逐阶段推进**。
- 后续阶段（AI视频场景选择 / 图片·视频·旁白生成 / 视频合成 / 发布）依次排队等待。
- 弹窗底部说明：合成时长与视频时长正相关（1 分钟视频合成 5–8 分钟、3 分钟 15–20 分钟、
  6 分钟 35–45 分钟），故完整出片耗时较长；**「视频生成产出实际 mp4」已由更早 turn 的 5/5 mp4
  端到端证据坐实**，本图仅证明前端「点击即自动改写→自动故事讲述流水线」交互流程活体成立。
