# 产品宣传文档（marketing）

项目上线后，所有**对外**的产品宣传材料统一放这里。

## 为什么单独建这个文件夹

研发文档和宣传文档的生命周期不一样：

- **研发文档**跟着代码走，功能改了就改，写给团队看
- **宣传文档**跟着市场认知走，改的是**说法**，不是功能，写给客户看

混在一起会互相污染——研发文档越写越厚，宣传素材埋在几十个文件底下没人找得到；
更麻烦的是有人改了宣传说法，回头看代码对不上，两边打起来。

## 四条使用纪律

1. **卖点清单是单一事实源。**
   对外文案里出现的任何一个卖点，都必须能在 `01` 里找到编号。
   找不到编号 = 现场编的，不能用。

2. **改文案前先看 `04`。**
   `04` 记录了每条卖点的代码证据和**已作废的说法**。
   不看就改，很容易把作废的话术又写回去。

3. **数字必须有出处。**
   平台数、并发数、账号上限、价格 —— 这类数字必须能在代码常量或官方文档里找到。
   拿测试样本当产品边界，是 v0.1 犯过的错（详见 `01` 顶部校准说明）。

4. **只追加不重排。**
   新卖点在清单末尾追加编号。编号会印到对外文案上，重排一次全废。
   （v0.1→v0.3 一直没重排，这条守住了。）
