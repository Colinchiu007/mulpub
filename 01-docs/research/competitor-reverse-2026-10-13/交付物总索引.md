## 7. 复现入口

所有脚本均可用 `node <脚本> [参数]` 直接跑，多数在文件头注释里写了用法与**事故背景**。

关键复现命令见各报告末尾的「复现方式」小节，或：

```powershell
$A = "D:\Data\projects\rea\analysis"

# 解 data.zip（GBK 文件名）
node "$A\extract-wemedia-datazip.cjs" "D:\Program Files (x86)\融媒宝\data.zip" "$A\wemedia-data-zip\data"
# 编码判定
node "$A\probe-wemedia-data-encoding.cjs" "$A\wemedia-data-zip\data"
# 分类体系（31 平台 / 11,623 节点；未识别则 exit 1）
node "$A\analyze-wemedia-taxonomy-v2.cjs" "$A\wemedia-data-zip\data"
# 其余文件形态
node "$A\probe-wemedia-data-misc.cjs" "$A\wemedia-data-zip\data"
# C1 缺陷复验（实测字符集）
node "$A\verify-wemedia-c1-escape-bug.cjs"
# 报告引用密度（双界）
node "$A\measure-report-citations.cjs" "$A\融媒宝-view-ai-clip拆解.md"
```
