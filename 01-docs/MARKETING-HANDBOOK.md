## 4. 价格策略

### 4.1 三层订阅模型

| 版本 | 价格 | 平台数 | 核心功能 | 目标用户 |
|------|------|:------:|---------|---------|
| **免费版** | ¥0 | 3 | 微信 + 任意 2 平台，每日 5 篇上限，基础 AI 写稿 | 个人创作者 |
| **Pro 版** | **¥39/月** 或 ¥299/年（省 36%） | 15+ | 全部平台 + 定时 + 批量 + 视频上传 + 统计看板 + 全部 AI | 自媒体运营 |
| **企业版** | ¥199/月 或 ¥1999/年 | 15+ | Pro 全部 + 多账号 + API 接入 + 团队协作 + SLA + 定制 | MCN/团队 |

### 4.2 详细功能边界

#### 免费版
- 3 个平台（微信 + 任意 2 个）
- 单篇发布
- 基础编辑器
- 每日最多 5 篇
- 本地账号存储 + AES-256-GCM 加密
- 基础 AI 写稿（限额）

#### Pro 版
- 全部 15+ 平台
- 批量发布（一键多平台）
- 定时发布
- 视频上传
- 发布历史 + 统计看板
- 无限篇数
- 全部 50+ AI Provider
- 13 视频创作 Pipeline
- 优先更新

#### 企业版
- Pro 全部功能
- 多账号（每平台 5+ 个账号）
- API 接口（PROJECT-001 集成）
- 团队协作（共享账号池）
- Logto OIDC 用户身份
- SLA 支持（24h 响应）
- 定制化开发
- Docker 私有部署

### 4.3 冷启动优惠（前 3 个月）

| 活动 | 内容 | 目标 |
|------|------|------|
| **早鸟价** | 前 200 名 Pro 年付 ¥99（原价 ¥299）终身锁定 | 制造稀缺感，加速前 200 转化 |
| **企业版首月免费** | 企业版首月 0 元试用 | 降低 B 端决策门槛 |
| **推荐机制** | 推荐 3 人付费，得 1 个月 Pro 免费 | 裂变增长 |
| **GitHub Star 福利** | Star 仓库 + 截图，送 1 个月 Pro | 开源飞轮 |
| **内容创作者计划** | 发布 Multi-Publish 教程视频，送 3 个月 Pro | UGC 内容沉淀 |

### 4.4 付费转化路径

```
免费体验 → 3 平台限制触发 → 升级弹窗 → 7 天 Pro 试用 → 付费订阅
```

**关键转化触发点**：
1. 第 3 次发布提示"已达到免费版每日上限"
2. 第 2 次选择第 4 个平台提示升级
3. 定时发布功能仅 Pro 可用
4. 首次使用后 72h 弹窗 Pro 7 天免费试用

- 支付宝 / 微信支付（国内）
- Stripe（海外，后续）
- 兑换码（早期用户赠送）

## 6. 转化漏斗设计（AARRR）

```
┌──────────────────────────────────────────────────┐
│ Awareness 认知（月 5 万 UV）                       │
│  SEO + 社区 + KOL + 开源                           │
│  ↓ 转化率 15%                                     │
├──────────────────────────────────────────────────┤
│ Acquisition 下载（月 7500 下载）                   │
│  官网 CTA + GitHub Release                         │
│  ↓ 转化率 60%                                     │
├──────────────────────────────────────────────────┤
│ Activation 激活（月 4500 首次发布）                 │
│  首次运行引导 + 第一个平台登录 + 首篇发布           │
│  ↓ 转化率 30%                                     │
├──────────────────────────────────────────────────┤
│ Retention 留存（月 1350 活跃）                     │
│  托盘常驻 + 全局快捷键 + 定时任务 + 数据看板         │
│  ↓ 转化率 8%                                      │
├──────────────────────────────────────────────────┤

└──────────────────────────────────────────────────┘
```

### 6.1 关键转化触发点（升级弹窗时机）

1. **第 3 次发布**：提示"已达到免费版每日上限"，引导升级
