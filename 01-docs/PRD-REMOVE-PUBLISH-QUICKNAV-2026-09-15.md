# PRD：移除发布域快捷标签行（新建发布 / 发布记录 / 草稿箱）

| 项 | 内容 |
|------|------|
| 文档版本 | v1.0（2026-09-15） |
| 状态 | 已实施（随本 PR 交付） |
| 变更类型 | 前端 UI 移除（纯展示层，零后端/数据变更） |
| 分支 | `codex/remove-publish-quicknav` |
| 关联规格 | `docs/desktop-ui-layout-spec.md` §3.1/§3.2/§3.4、`docs/frontend-interaction-spec.md` §6.3 |

---

## 1. 背景与问题

应用壳在首页标签（`isHomeTab === true`）激活时，会在 `TabBar` 与 `NavBar` 下方渲染模块导航栏 `MpModuleNav`。该组件按当前路由域显示一组快捷标签：

- 首页域（`/`）：「主页」
- 账号域（`/accounts*`）：「账号管理 / 分组管理 / 分享链接 / 收藏分组」
- **发布域（其余全部 SPA 路由）**：「新建发布 / 发布记录 / 草稿箱」

问题：发布域快捷标签行在**所有非首页、非账号域路由**下都会渲染——包括采集页（`/collection`）、文案改写、数据看板等与发布流程无关的页面。用户在采集页看到的这一行（「新建发布 / 发布记录 / 草稿箱」）与当前页面内容毫无关联，且与左侧边栏的导航职责完全重复（侧边栏已有「发布」「草稿」「采集」等入口），属于界面噪音与认知负担。

## 2. 目标与非目标

### 2.1 目标

1. 发布域路由下，模块导航**整行移除**：无标签、无 70px 占位高度、无底部分隔线；`NavBar` 直接衔接主内容区。
2. 主页域与账号域的模块导航行为**保持不变**（这两个域的标签与当前页面直接相关）。
3. 发布域各页面入口可达性不回退：`新建发布`（`/publish`）、`草稿箱`（`/publish?tab=drafts`）、`采集`（`/collection`）由左侧边栏直达；`发布记录`（`/publish/history`）经发布页内既有「发布记录」入口或地址路由到达。
4. 零后端/数据/IPC 变更，纯前端展示层调整。

### 2.2 非目标

- 不改动主页域「主页」标签与账号域四标签的渲染与激活逻辑。
- 不改动左侧边栏（`MpSidebar`）结构。
- 不引入任何新导航入口（发布记录若需侧边栏直达入口属独立需求，另行评审）。

## 3. 用户故事

- **作为**采集页用户，**我希望**页面上不再出现与采集无关的「新建发布 / 发布记录 / 草稿箱」链接行，**以便**界面聚焦当前任务、减少误导性导航。
- **作为**发布页用户，**我希望**仍能从侧边栏一键到达发布、草稿箱与采集，**以便**移除快捷标签行后导航效率不下降。

## 4. 功能逻辑（实现规格）

### 4.1 组件行为（`apps/desktop/src/layouts/MpModuleNav.vue`）

| 项 | 规格 |
|------|------|
| 挂载条件 | `App.vue`：`<MpModuleNav v-if="isHomeTab" />`（不变） |
| 域判定 | `module` 计算属性：`/` → `home`；`/accounts*` → `accounts`；其余 → `publish`（不变） |
| 标签数据 | **删除** `publishTabs` 数组（`new-publish` / `publish-history` / `drafts` 三项） |
| 标签输出 | `tabs` 计算属性：`home` → `homeTabs`；`accounts` → `accountTabs`；**`publish` → 空数组 `[]`** |
| 渲染条件 | 模板根节点 `<nav v-if="tabs.length > 0">`：空标签时整行不渲染（无 DOM 节点，无 70px 高度，无 `border-bottom` 分隔线） |
| 激活判定 | `isTabActive` 删除发布域三个分支；发布域恒返回 `false`（防御性兜底，正常流程不会以发布域 tab 调用） |

### 4.2 交互逻辑

| 场景 | 移除前 | 移除后 |
|------|--------|--------|
| 首页标签激活 + 位于 `/` | 显示「主页」标签行 | **不变**（显示） |
| 首页标签激活 + 位于 `/accounts*` | 显示账号四标签行（支持 `?tab=` 查询参数高亮） | **不变**（显示） |
| 首页标签激活 + 位于 `/publish`、`/publish/history`、`/publish?tab=drafts`、`/collection` 等 | 显示「新建发布 / 发布记录 / 草稿箱」标签行 | **整行不渲染**；`NavBar` 直接衔接 `.mp-workspace`，主内容整体上移 70px |
| 浏览器标签 / 登录标签激活 | 模块导航隐藏（WebContentsView 占据主体） | **不变** |
| 点击已移除的标签 | 路由跳转 | 入口不存在；无残留热区，无空 `role="tab"` 语义节点 |

### 4.3 显示项与提示文字

- **移除的显示项**：`新建发布`、`发布记录`、`草稿箱` 三个 `router-link` 标签及激活态下划线指示条。
- **无新增显示项、无新增提示文字**：本变更纯移除，不新增任何用户可见文案，不涉及 i18n 词条（原标签为组件内硬编码中文，随组件代码一并删除，不产生 i18n 孤儿键）。

### 4.4 数据校验

- **不涉及**：本变更不含表单、接口、存储与 IPC 交互；无数据读写。路由跳转能力由 `vue-router` 既有机制承担，无新增校验需求。

### 4.5 状态与边界

| 边界 | 行为 |
|------|------|
| 未知路由（既非 `/` 也非 `/accounts*`） | 归入发布域 → 导航整行不渲染（fail-safe：宁可少渲染，不渲染无关标签） |
| 直达 URL / hash 路由进入发布域 | 同上，整行不渲染 |
| 窄屏（≤700px） | 发布域整行不渲染的规则与视口无关，一致生效；主页/账号域保留既有横向滚动行为 |
| `prefers-reduced-motion` | 不涉及（无动画变更） |

## 5. 验收标准

1. 采集页（`/collection`）顶部不再出现「新建发布 / 发布记录 / 草稿箱」链接行，且不留空白条与分隔线。
2. 发布页（`/publish`）、发布记录页（`/publish/history`）、草稿箱（`/publish?tab=drafts`）同样不再出现该行。
3. 主页（`/`）仍显示「主页」标签行；账号管理（`/accounts`）仍显示账号四标签行且激活态正确。
4. 从侧边栏可正常到达：发布、草稿箱、采集；发布记录可经发布页内入口或地址路由到达。
5. 无障碍：发布域路由下页面中不存在 `role="tab"` / `role="tablist"` 的模块导航节点。
6. 单测回归保护全部通过（见第 7 节）。

## 6. 影响面与风险

| 影响点 | 说明 | 处置 |
|--------|------|------|
| e2e 发布流程 | `tests/e2e/publish-flow.test.js` 原经 `mp-tab-publish-history` 标签跳转发布记录 | 已改为 `window.location.hash = '#/publish/history'` 导航（与 `electron-gui-v9.js` 既有 hash 导航模式一致） |
| 视觉基线 | `tests/visual-testing/base-screenshots/` 基线在 ipc-mock 空态下 `isHomeTab === false`，模块导航本就不在基线中 | **零影响**，无需重建基线 |
| GUI 冒烟脚本 | `tests/electron-gui-v9.js` 仅在 `/accounts` 路由断言模块导航（账号域，保留） | **零影响** |
| 布局检查脚本 | `capture-mp-current.js` 的导航重叠检查为 `if (nav && main)` 容错，导航不存在时自动跳过 | **零影响** |
| 全局标签残留 | 全仓已无 `mp-tab-new-publish` / `mp-tab-publish-history` / `mp-tab-drafts` / `publishTabs` 引用 | 已核实归零 |

## 7. 回归保护测试（`apps/desktop/src/layouts/MpModuleNav.test.js`）

以「发布域不渲染模块导航」用例替代原「发布域标签激活态」用例，断言四条代表性发布域路由（`/publish`、`/publish/history`、`/publish?tab=drafts`、`/collection`）：

1. `[data-testid="mp-module-nav"]` 不存在；
2. 页面内 `role="tab"` 节点数为 0；
3. 文本不含 `新建发布` / `发布记录` / `草稿箱`。

既有用例保持不变：账号域四标签与激活态（含 `?tab=` 查询参数切换）、主页域标签、工具区移除回归。
