## 1. 一句话定位

> **Multi-Publish 是一款开源 MIT 协议的「AI 内容工作站」，集成 15+ 平台 RPA+API 双模式发布、50+ AI 服务商、13 视频创作管线，Cookie 本地 AES-256-GCM 加密、可离线运行，让创作者从「采集 → 改写 → 视频 → 多发」一站式闭环。**

### 关键词解码

| 关键词 | 战略意图 |
|--------|---------|
| **开源 MIT** | 建立信任 + B 端可二次开发（差异化护城河） |
| **AI 内容工作站** | 升级品类，避开"多发工具"红海，锚定"创作 + 发布"全链路 |
| **15+ 平台** | 数量碾压竞品（参考产品 5-7），数据亮点 |
| **RPA+API 双模式** | 稳定性优势，自动降级，技术深度 |
| **本地加密 + 离线** | 隐私合规（行业趋势），B 端关键决策点 |
| **一站式闭环** | 工作流价值，不止单点功能，提升替换成本 |

## 5. 三层用户价值主张

### Tier 1：自媒体运营者（核心付费）

- **痛点**：5-10 平台手动切换累、排版重复、定时发布要值夜班、AI 工具零散付费
- **价值主张**：
  > **"15 平台一键发，AI 写稿 + 视频创作全免费，¥39/月比参考产品便宜 20%"**
- **核心证据**：15 平台矩阵 + 50+ AI Provider + 13 视频管线 + ¥39 vs ¥49 对比

### Tier 2：MCN/企业团队（高价值）

- **痛点**：团队协作乱、账号管理难、Cookie 上云合规风险、API 接入需求
- **价值主张**：
  > **"开源可二次开发，Cookie 本地加密合规，API 接入内部系统，¥199/月团队版"**
- **核心证据**：MIT 协议 + AES-256-GCM + Logto OIDC + 云端发布 API + Docker 部署

### Tier 3：个人创作者（流量入口）

- **痛点**：免费工具少、功能受限、隐私担忧
- **价值主张**：
  > **"免费开源，3 平台够用，AI 帮你写稿，Cookie 永不上云"**
- **核心证据**：MIT 协议 + 免费版 3 平台 + AI 写作 + 本地加密

```
        Buffer/Later   │      参考产品
        ($15-65, 海外)  │   (¥49, 市占第一但平台少)
                       │
                       │  ★ Multi-Publish
                       │  (¥39, 开源+AI+视频+15平台)
                    低价格
```

### 占位分析

**Multi-Publish 占位**：**低价 + AI 增强 + 开源 + 全模式** — 四象限中独一无二

- 低价象限：唯一同时具备 AI + 视频的开源产品
- AI 增强象限：唯一同时具备开源 + 低价的全平台产品
- 开源象限：唯一同时具备 AI + 低价的全模式产品
- 全模式象限：唯一同时具备开源 + AI 的低价产品

## 7. 竞品差异化矩阵

基于 `MARKET-RESEARCH.md` §2 竞品矩阵对比：

| 维度 | Multi-Publish | 参考产品 | 融媒宝 | Newrank | Buffer/Later |
|------|:------:|:------:|:------:|:------:|:------:|
| **价格** | ¥39/月 | ¥49/月 | ¥99/月起 | ¥299/月 | $15-65/月 |
| **平台数** | 15+ | 5-7 | 40+ | 10 | 8（不支持国内） |
| **发布模式** | **API+RPA 双模式** | 纯 RPA | 纯 RPA | API+RPA | 纯 API |
| **开源** | ✅ MIT | ❌ 闭源 | ❌ 闭源 | ❌ 闭源 | ❌ 闭源 |
| **离线** | ✅ 本地 Cookie | ❌ 上云 | ❌ 上云 | ❌ 上云 | ❌ 上云 |
| **AI 增强** | ✅ 50+ Provider | ❌ | ❌ | 数据分析强 | ❌ |
| **视频创作** | ✅ Remotion + Story2Video | ❌ | ❌ | ❌ | ❌ |
| **用户身份** | ✅ Logto OIDC | ❌ | ❌ | ❌ | 自有 |
| **海外平台** | ✅ YT/TikTok/IG/FB/X | ❌ | ❌ | ❌ | ✅ |

### 五大核心差异化优势

1. **API + RPA 双模式 + 自动降级** — 竞品多为纯 RPA，稳定性差；Multi-Publish API 优先 + RPA 兜底，连续失败 3 次自动切换
2. **开源 + 离线** — Cookie 不上云，AES-256-GCM 本地加密，隐私安全（行业趋势：隐私合规趋严）
3. **AI 增强（50+ 服务商）** — 标题/标签/爆款分析/视频创作全链路 AI；竞品基本无 AI
4. **15 平台覆盖（含海外）** — 优于参考产品 5-7，价格仅 40% vs 融媒宝
5. **完整视频创作管线** — 13 种 Pipeline + Remotion 13 Composition + Story2Video 真实 ffmpeg 合成，竞品无任何视频能力

> Multi-Publish 不是一个"多发工具"，而是**创作者的内容工厂**。
> 从一个想法，到全网触达，你只需要一个工作站。

## 13. 风险与应对

| 风险 | 等级 | 应对策略 |
|------|:----:|---------|
| 平台 API 收紧/封禁 | 高 | RPA fallback + 多账号轮换 + 反检测（stealth + 随机延迟） |
| 融媒宝/参考产品降价 | 中 | 以开源 + AI 差异化应对，不拼价格；前 200 名早鸟锁定用户 |
| 新产品品牌力弱 | 中 | 开源飞轮 + GitHub Star + 内容营销 + KOL 合作 |
| Logto 真实租户未验收 | 中 | 标为边界，企业版销售前完成真实租户验收 |
| 海外平台 RPA 失效 | 中 | OAuth 2.0 优先 + RPA 兜底 + 监控告警 |
