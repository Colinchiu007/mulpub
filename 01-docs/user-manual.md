# Multi-Publish 快速上手手册

> 10 平台内容一键发布工具（微信/知乎/微博/抖音/小红书/视频号/快手/今日头条/YouTube/TikTok）

---

## 1. 安装

1. 前往 [GitHub Releases](https://github.com/Colinchiu007/Multi-Publish/releases) 下载最新版
2. Windows: 运行 `Multi-Publish.Setup.x.x.x.exe` 安装
3. 安装完成后桌面出现 `Multi-Publish` 图标，双击启动

---

## 2. 首次启动

启动后 App 自动完成：
- ✅ 检测 Python 环境
- ✅ 安装 Python 依赖
- ✅ 安装 Playwright 浏览器
- ✅ 启动后端服务

**注意：** 首次启动可能需要 1-2 分钟，取决于网络速度。

---

## 3. 添加账号

**步骤：**
1. 左侧导航 → **账号管理**
2. 点击 "+ 新增账号"
3. 选择平台（如"微信公众号"）
4. 弹出浏览器窗口 → 扫码登录
5. 登录成功后自动关闭窗口
6. 账号列表中显示新账号 ✅

**支持的登录方式：**
| 平台 | 登录方式 |
|------|---------|
| 微信公众号 | 微信扫码 |
| 知乎 | 账号密码 / 手机号 |
| 微博 | 扫码 / 账号密码 |
| 抖音 | 扫码 / 手机号 |
| 小红书 | 扫码 / 账号密码 |
| 视频号 | 微信扫码 |
| 快手 | 手机号 / 账号密码 |
| 今日头条 | 扫码 / 账号密码 |
| YouTube | Google 账号 |
| TikTok | 扫码 / 账号密码 |

### 3.1 批量重新登录（登录失效后）

1. 首页顶部出现「登录失效提醒」横幅 → 点击 **「批量登录」**
2. 每个失效账号自动打开一个浏览器标签 → 在标签内扫码 / 输入账密完成登录
3. **登录成功后约 1.5 秒自动保存凭证**，标签上的橙色「未保存」角标自动熄灭；
   也可随时点击导航栏 **「保存账号」** 或横幅 **「全部保存（n）」** 手动保存
4. 关闭尚未保存的账号标签时会弹出确认：**保存并关闭 / 直接关闭 / 取消**

> 角标、按钮脉冲与「全部保存」只针对「重新登录但凭证尚未保存」的账号标签，
> 普通浏览标签不受影响。详细机制见 product-manual.md §4.3。

## 4. 发布内容

**图文发布：**
1. 左侧导航 → **一键发布**
2. 选择目标平台（可多选）
3. 输入标题
4. 在富文本编辑器中撰写内容（支持图片粘贴）
5. 点击 **发布**

**视频发布（抖音/视频号/快手/今日头条/YouTube/TikTok）：**
1. 选择支持视频的平台
2. 拖拽视频文件到上传区域（支持 mp4/mov/avi）
3. 填写标题和描述
4. 点击 **发布**

---

## 5. 批量发布 & 定时发布

**批量发布：**
- 选择多个平台 → 一键发布到所有选定平台

**定时发布：**
- 在发布页面设置发布时间的日期和时
- 到时间自动发布
- App 关闭后重启会恢复未执行的定时任务

## 7. 自动更新

App 启动 3 秒后自动检测新版本：

- **发现新版本** → 侧边栏左下角（登录头像上方）出现「**新版本**」按钮（圆形底 + 向上箭头图标）
  - **点击它** → 开始下载 → 下载完成后**应用自动退出并安装新版本**（点击即表示同意退出）
  - 下载过程中按钮显示「下载中 42%」并不可重复点击
  - 若安装包已提前下载好，按钮显示「重启安装」，点击即退出安装
  - 点失败（如网络中断）→ 按钮变「重试安装」，可再点一次
- **没有新版本** → 不显示按钮，右下角短暂提示「当前已是最新版本」
- **更新失败** → 右下角出现「更新失败：<原因>」提示条
- 不再弹出更新对话框，运行期间也不会中断你的操作

> 安装会关闭当前应用。若正在跑发布/创作任务，建议先等任务结束再点击「新版本」。

## 8. 常见问题

**Q: 添加账号时浏览器窗口不弹出？**
A: 检查是否被防火墙拦截，或手动关闭浏览器弹窗拦截。

**Q: 发布失败怎么办？**
A: 检查账号登录状态，账号过期时需重新登录。

**Q: 视频上传支持哪些格式？**
A: mp4、mov、avi。文件大小建议不超过 500MB。

**Q: 能否同时在多台电脑使用？**
A: 免费版限 1 台，Pro 版限 3 台，企业版不限。
## 9. 视频创作管线

> 功能状态: 🧪 Beta — 需 Python 后端运行

### 9.1 进入创作模式

在主界面点击「视频创作」进入 PipelineBrowser 管线浏览器，可以看到所有可用的视频制作管线。

### 9.2 选择管线

管线按类型分类（动画、解说、口播等），每张卡片显示：
- **类别标签**：动画/解说/口播/AI 生成等
- **管线名称**：如 animated-explainer、talking-head
- **描述**：管线功能简介
- **稳定性**：experimental / stable / deprecated

点击卡片开始配置该管线的参数。

### 9.3 管线类型

| 管线 | 说明 | 稳定性 |
|------|------|--------|
| animated-explainer | AI 动画解说视频 | stable |
| talking-head | 数字人口播视频 | experimental |
| clip-montage | 素材混剪 | experimental |
| hyper-lapse | 延时摄影 | experimental |
| slideshow | 幻灯展示 | experimental |
| tutorial-capture | 教程录屏 | experimental |

### 9.4 技术要求

- Python 后端需要在本地运行（默认端口 8299）
- 部分 AI 管线需要 API Key（在设置中配置）
- 渲染视频会占用 CPU/GPU 资源
