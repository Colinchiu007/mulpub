# Multi-Publish 快速上手手册

> 10 平台内容一键发布工具（微信/知乎/微博/抖音/小红书/视频号/快手/今日头条/YouTube/TikTok）

---

## 1. 安装

1. 前往 [GitHub Releases](https://github.com/Colinchiu007/Multi-Publish/releases) 下载最新版
2. Windows: 运行 `Multi-Publish.Setup.x.x.x.exe` 安装
3. 安装完成后桌面出现 `Multi-Publish` 图标，双击启动

---

## 2. 首次启动

启动后 App 自动完成：
- ✅ 检测 Python 环境
- ✅ 安装 Python 依赖
- ✅ 安装 Playwright 浏览器
- ✅ 启动后端服务

**注意：** 首次启动可能需要 1-2 分钟，取决于网络速度。

### 3.1 批量重新登录（登录失效后）

1. 首页顶部出现「登录失效提醒」横幅 → 点击 **「批量登录」**
2. 每个失效账号自动打开一个浏览器标签 → 在标签内扫码 / 输入账密完成登录
3. **登录成功后约 1.5 秒自动保存凭证**，标签上的橙色「未保存」角标自动熄灭；

> 角标、按钮脉冲与「全部保存」只针对「重新登录但凭证尚未保存」的账号标签，
> 普通浏览标签不受影响。详细机制见 product-manual.md §4.3。

## 7. 自动更新

App 启动 3 秒后自动检测新版本：

- **发现新版本** → 侧边栏左下角（登录头像上方）出现「**新版本**」按钮（圆形底 + 向上箭头图标）
  - **点击它** → 开始下载 → 下载完成后**应用自动退出并安装新版本**（点击即表示同意退出）
  - 下载过程中按钮显示「下载中 42%」并不可重复点击
  - 若安装包已提前下载好，按钮显示「重启安装」，点击即退出安装

- **没有新版本** → 不显示按钮，右下角短暂提示「当前已是最新版本」
- **更新失败** → 右下角出现「更新失败：<原因>」提示条
- 不再弹出更新对话框，运行期间也不会中断你的操作

> 安装会关闭当前应用。若正在跑发布/创作任务，建议先等任务结束再点击「新版本」。

## 8. 常见问题

**Q: 添加账号时浏览器窗口不弹出？**
A: 检查是否被防火墙拦截，或手动关闭浏览器弹窗拦截。

**Q: 发布失败怎么办？**
A: 检查账号登录状态，账号过期时需重新登录。

**Q: 视频上传支持哪些格式？**
A: mp4、mov、avi。文件大小建议不超过 500MB。

**Q: 能否同时在多台电脑使用？**
A: 免费版限 1 台，Pro 版限 3 台，企业版不限。

### 9.3.1 数字人口播（avatar-spokesperson）

**前置条件**

1. 在「设置 → 模型服务商」中添加数字人服务商并填入有效的 API Key。目前支持两家：
   **HeyGen** 与 **飞影 HiFly**（在「数字人提供方」下拉里切换，两家的形象/音色列表与能力各自独立）。
2. 确保已配置一个可用的**推理模型（LLM）**——它负责把你的主题写成口播文案。

**操作步骤**

1. 在视频创作页选中「数字人口播」卡片。
2. 页面出现「数字人」配置区，系统自动从 HeyGen 拉取可用列表：
   - **数字人形象**：账号下可用的数字人（名称来自 HeyGen `/v2/avatars`）。
   - **数字人音色**：可用配音音色（来自 HeyGen `/v2/voices`）。
   - 若列表为空或加载失败，点「刷新列表」重试；仍失败会显示「前往配置」引导。
3. 在输入框填写**主题**（一句话即可，LLM 会据此扩写成 100–200 字口播文案）。
4. 点「启动流水线」。

**状态与提示**

| 情况 | 页面表现 | 如何处理 |
|------|---------|---------|
| 列表加载中 | 下拉禁用 + 「正在加载数字人列表…」 | 等待 |
| 未配置 HeyGen | 整区替换为「使用数字人需要在模型设置中配置 HeyGen」+「前往配置 →」 | 点击链接去配置 |
| 列表加载失败（曾成功过） | 保留上次列表，红字提示「列表为缓存数据，刷新失败：…」 | 点「刷新列表」 |
| 列表为空 | 「未获取到可用数字人形象，请检查 HeyGen 配置」 | 检查 Key / 账号是否有可用形象 |
| 未选形象 | 启动按钮禁用，下方常驻提示「请先选择数字人形象」 | 选一个形象 |
| 未选音色 | 启动按钮禁用，下方常驻提示「请先选择数字人音色」 | 选一个音色 |

**执行流程**（后台自动推进，可在进度区查看）

```
avatar_select  → LLM 按主题写口播文案（约数秒）
script         → 口播文案
generate       → 提交 HeyGen 生成数字人视频（轮询，上限 10 分钟）
render         → FFmpeg 拼接 → 成片
```

**注意事项**

- 数字人视频**一次生成即成片**（单场景），不做多分镜；成片时长取决于口播文案长度。
- 数字人生成走服务商配额（HeyGen 限制 8 次/分钟、并发 2；飞影按账户积分计费），批量创作时会自动排队。
- 数字人形象/音色列表缓存 5 分钟；换 API Key 后点「刷新列表」立即生效。
- 数字人形象预览图不下载到本机，界面只展示名称。
- **形象克隆与声音克隆是两条独立链路**：先在「数字人 → 管理克隆形象」里上传素材克隆出形象（和配套音色），之后生成视频时只是**引用**已克隆的 `avatar_id` / `voice_id`，不会在生成视频时一并训练。
- 克隆出来的形象/音色**跟着账号走**：存在本地按账号隔离的 registry 里，换电脑后同一账号能看到同一批（前提是服务商侧资源仍在）。

#### 切换数字人服务商（digital-human-multiprovider）

数字人支持多家服务商，在「数字人」配置区顶部的「**数字人服务商**」下拉里切换。

| 状态 | 界面表现 |
|---|---|
| 只配了一家 | 下拉只有一项且不可点，附提示「当前仅配置了一家数字人服务商，切换需先在模型设置中添加」 |
| 配了多家 | 下拉可切；切换后**自动**清空已选形象与音色，并重新拉取新服务商的形象、音色、克隆列表 |
| 一家都没配 | 整区变成「前往配置」引导 |

**切换时会发生什么**

1. 已选的「数字人形象」和「数字人音色」被清空——两家的形象/音色 id 格式相同，不清空会误选到另一家的资源；
2. 形象列表、音色列表、克隆形象列表**全部重拉**（它们按服务商分别存放，不会串；
   你在 HeyGen 克隆的形象不会出现在飞影的下拉里，反之亦然）；
3. 克隆面板里已创建的克隆形象仍归属原服务商，切回来还能看到。

**注意事项**

- 克隆形象**不跨服务商共享**：在 HeyGen 克隆的形象只能用 HeyGen 生成视频，飞影同理。
  这是服务商的资源隔离，不是应用限制。
- 切换服务商不影响已保存的流水线配置；重新选好形象与音色后再启动即可。

#### 克隆自己的声音（与形象克隆互补）

形象和声音都可在**同一个「管理克隆形象」面板**里完成，互不干扰：

| 想克隆什么 | 去哪里 | 传什么 |
|---|---|---|
| 数字人形象 | 数字人配置区 →「管理克隆形象」 | 一张照片或一段视频 |
| 数字人声音 | 数字人配置区 →「管理克隆形象」→「**克隆我的声音**」 | 一段录音（mp3 / m4a / wav） |

**操作步骤（声音）**

1. 选中「数字人口播」流水线，点「管理克隆形象」展开面板。
2. 找到「**克隆我的声音**」区（只有当前服务商支持克隆声音时才出现）。
3. 填「音色名称」，点「选择本地录音文件」。
4. 等待创建完成，提示「已创建音色「xxx」」。
5. 该音色随即出现在上方「数字人音色」下拉里，与现成音色混排。

**素材要求**（以服务商官方为准）

| 服务商 | 格式 | 大小 / 时长 | 数量上限 |
|---|---|---|---|
| HeyGen | — | 见面板内的能力提示 | — |
| 飞影 HiFly | mp3 / m4a / wav | ≤20MB，5 秒～3 分钟 | 同账号 200 个 |

**注意事项**

- 「管理克隆形象」面板里，若当前服务商**不支持**克隆声音，会直接说明「只能用现成音色」——这不是故障，换一家支持的服务商即可。
- 克隆音色与克隆形象一样**跟着账号走、按服务商隔离**：在 HeyGen 克隆的声音不会出现在飞影的音色下拉里。
- 如需重命名/删除克隆音色，去「配音」区的「音色复制 / 克隆」完整面板操作（那里有完整列表管理）。

#### 给数字人视频加字幕（飞影 HiFly）

**仅飞影 HiFly 支持**。HeyGen 的视频接口没有字幕参数，所以这项对 HeyGen 不显示。

1. 选中「数字人口播」流水线，确认「数字人服务商」选的是飞影 HiFly。
2. 在「数字人音色」下方点「**添加字幕**」。
3. 展开后可设置：字体（留空用服务商默认）、字号、文字颜色、描边颜色。
4. 字幕会烧录进成片；改样式不用重新克隆形象，重新生成视频即可生效。

**说明**

- 字幕的**位置与区域大小**暂用服务商默认值，应用内不调整。
- 不想加字幕就别展开这个开关——开关关闭时不会向服务商发任何字幕参数，用服务商自己的默认行为（不显示）。
- 字幕文案就是你的口播文案，不能在应用内单独编辑。

#### 克隆自己的数字人形象（avatar-voice-clone）

**前置条件**：已在「设置 → 模型服务商」配置至少一家数字人服务商（HeyGen 或飞影 HiFly），并在「数字人服务商」下拉里选中它。

**操作步骤**

1. 选中「数字人口播」流水线，点数字人配置区的「**管理克隆形象**」。
2. 首次打开会看到一段法律提示（肖像权/声音权归上传者所有、不得克隆他人）。点「我已了解」关闭——**不强制勾选，但请自行确认已获授权**。
3. 填「形象名称」，然后二选一：
   - 「**用照片创建**」——单张正面照片，最快，官方不要求额外 consent 步骤；
   - 「**用视频创建**」——一段视频素材，训练出的形象更自然。
4. 在弹出的文件对话框里选素材（只能选对应类型：照片入口只列图片、视频入口只列视频）。
5. 等训练完成（通常几分钟，列表里显示「训练中…」）。完成后该形象就出现在形象下拉里，名称带「我上传的」后缀。

**状态与提示**

| 状态 | 含义 | 如何处理 |
|---|---|---|
| 训练中… | 服务商正在训练 | 等列表状态变成可用 |
| 训练失败 | 素材不合要求或服务侧拒绝 | 删掉它，换素材重建 |
| 远端已不存在 | 服务商侧该形象已被删（如账号变动） | 删除本地记录后重新克隆 |
| 本地素材已缺失 | 本机留存的上传素材被清理 | 形象仍可用（服务商侧还在），只是不能再「用样本重新克隆」 |
| 当前服务商暂时不可用 | 该服务商的克隆能力尚未开放 | 换一家支持克隆的服务商，或等待后续版本 |

**关于「当前服务商暂时不可用」**：这是**预期的安全行为**，不是故障。
为避免把「字段名猜错」的请求发到服务商（那会产生难排查的半截状态），
克隆能力在正式开放前会被拦住。当前 HeyGen 与飞影的克隆入口都处于这一状态，
**生成数字人视频本身不受影响**——你仍然可以用服务商提供的现成形象与音色。

**注意事项**

- 本功能面向「克隆**你自己**（或你已获授权的人）」；使用他人肖像或声音产生的法律责任由使用者承担。
- 删除克隆形象会**同时删服务商侧资源**；若远端删除失败，本地会保留记录并标记待删，下次重试。
- 克隆素材（照片/视频）会在本机 `userData/avatar-clone-samples/<服务商>/<账号>/` 留一份，用于必要时重新克隆；删除形象时会一起清理。
- 克隆形象**按服务商隔离**：在 HeyGen 克隆的形象不会出现在飞影的形象下拉里，反之亦然。这是服务商的资源隔离，不是应用限制。
- **飞影的素材上传是自动的**：选好文件后，应用会自动完成「换取上传地址 → 上传 → 获取文件 id」，不需要你手动把文件传到别处再填链接。

#### HeyGen 在这条管线里承担什么

数字人口播管线分四个阶段，HeyGen 只出现在第三个，而且是**唯一的数字人供应商**：

| 阶段 | 谁干活 | 干什么 |
|------|--------|--------|
| `avatar_select` | 默认 LLM | 校验形象/音色已选，把你的**主题**写成口播文案 |
| `script` | 默认 LLM | 复用同一份文案 |
| `generate` | **HeyGen** | 提交（形象 + 音色 + 文案）→ 轮询 → 下载成片 |
| `render` | 本地 FFmpeg | 单场景直拷为最终成片 |

HeyGen 和通用文生视频（Kling / Runway / Veo 等）**不是同一条链路**：数字人分支收的是「形象 + 音色 + 文案」三要素，不是画面提示词，因此不会走提示词优化，也不受通用视频模型默认供应商的影响（默认视频模型换成别家时，数字人仍然固定走 HeyGen）。

#### 数据怎么流到 HeyGen

```
选「数字人口播」卡片
  → 前端拉形象/音色列表：GET /v2/avatars、/v2/voices（5 分钟缓存，可手动刷新）
点「启动流水线」
  → 启动前校验：形象已选 → 音色已选 → HeyGen 已配置且可用 → 默认 LLM 可用
  → 任一不过直接拦下，不会创建半截任务
generate 阶段
  → POST /v2/video/generate        （形象/音色/文案组装成官方请求体）
  → GET /v1/video_status.get?video_id=…  每 10 秒轮询一次，上限 10 分钟
  → 拿到 video_url 后下载为本地场景文件
render 阶段
  → FFmpeg 拼成最终成片
```

三要素任一缺失时，流水线在本地就直接失败并给出可操作的提示，不会把不完整的请求发给 HeyGen。

### 9.3.2 飞影 HiFly 支持的能力范围

飞影提供的能力比 HeyGen 更宽，且**按 provider 切换**——切到飞影时才会看到下面这些；
切回 HeyGen 时只显示 HeyGen 支持的部分（不支持的能力不会灰着占位，而是不显示）。

**形象与声音（克隆线）**

| 能力 | 说明 | 消耗积分 |
|---|---|---|
| 克隆形象（上传视频） | 5 秒 ~ 30 分钟、500MB 以内、mp4/mov（h264） | **不消耗** |
| 克隆形象（上传图片） | 单张人像图 | **消耗**（额度以飞影控制台为准） |
| 克隆声音 | mp3 / m4a / wav，5 秒 ~ 3 分钟，20MB 以内，需含清晰人声 | **不消耗** |
| 调整音色参数 | 语速 0.5~2.0、音量与语调 0.1~2.0 | **不消耗** |

**创作线（6 种模式，都消耗积分）**

| 模式 | 你给什么 | 得到什么 |
|---|---|---|
| 文本驱动（已有） | 文案 + 形象 + 音色 | 数字人口播视频 |
| **声音驱动** | 一段录音 + 形象 | 数字人按你的录音说话（口型跟着音频） |
| **网感模板** | 文案 + 模板 + 形象 + 音色 | 套好版式 / BGM 的成片 |
| **视频翻译** | 一段视频 + 目标语言 | 换语言的成片（≤10 分钟） |
| **唱歌** | 一张图 + 一段音频 | 图片人物跟着唱（音频 ≤60 秒） |
| **图片驱动** | 一张图 + 文案 + 音色 | 静态图变成会说话的视频 |
| **音频创作** | 文案 + 音色 | 纯音频（可再拿去驱动数字人） |

**辅助能力**

- **查询账户积分**：看到剩余额度，避免提交后才发现不够。
- **网感模板 / 封面模板列表**：浏览平台提供的模板。
- **创建封面**：用模板 + 文案生成封面图。**不消耗积分**（与视频创作不同）。
- **删除作品**：删除已生成的视频。注意**只有「文本驱动」生成的作品能删**——
  翻译、唱歌、图片驱动的作品飞影不支持删除。

> **界面入口状态**：以上能力当前已在应用内部就绪，界面入口会分批开放。
> 若你在界面上还看不到某个模式，说明它尚未接入 UI（不是没有实现）。
