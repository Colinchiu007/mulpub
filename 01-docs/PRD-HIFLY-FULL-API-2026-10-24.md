- 日期：2026-10-24
- 分支：`hifly-full-api`

## 一、背景与目标

### 1.1 现状

数字人功能此前已实现 **12 个端点**，集中在「克隆」这条线：

| 类别 | 已实现 |
|---|---|
| 形象克隆 | `avatar/create_by_video`、`avatar/create_by_image`、`avatar/task`、`avatar/list`、`DELETE avatar` |
| 声音克隆 | `voice/create`、`voice/edit`、`voice/list`、`voice/task` |
| 创作 | `video/create_by_tts`（文本驱动）、`video/task`、`tool/create_upload_url` + PUT |

「创作」这条线只做了**文本驱动**一种模式。

### 1.2 本次目标

把官方剩余 **11 个端点**全部实现，使飞影能力面**完整覆盖**（唯一例外是「消息回调」，见 §5.1）。

| # | 端点 | 能力 | 计费 |
|---|---|---|---|
| 1 | `GET /account/credit` | 查询账户积分 | 免费 |
| 2 | `GET /video/lively_templates` | 查询网感模板列表 | 免费 |
| 3 | `GET /project/cover_styles` | 查询封面模板列表 | 免费 |
| 4 | `POST /project/covers` | 创建封面 | **免费** |
| 5 | `DELETE /video/task` | 删除作品 | 免费 |
| 6 | `POST /video/create_by_audio` | 视频创作（声音驱动） | **收费** |
| 7 | `POST /video/create_by_template` | 视频创作（网感模板） | **收费** |
| 8 | `POST /video/translate` | 视频翻译 | **收费** |
| 9 | `POST /video/create_by_sing` | 视频创作（唱歌） | **收费** |
| 10 | `POST /video/create_by_image` | 视频创作（图片驱动） | **收费** |
| 11 | `POST /audio/create_by_tts` | 音频创作 | **收费** |

### 1.3 计费口径（逐条核对官方文档）

**这是本 PRD 最重要的一条约束**：6 个创作端点全部标注「此接口会产生积分消耗」，其余 5 个免费。

尤其注意：**创建封面是免费的**——它是全项目唯一的「免费创建类」端点。这一点与直觉相反（同为「创建」，视频创作收费而封面不收费），实现与 UI 都必须按这条走。

## 二、代码结构

### 2.1 为什么拆成两个新文件

`hifly.js` 已 465 行，`check-max-lines.js` 的硬线是 **500 行**，只剩 35 行余量。11 个端点约 650 行代码，必须外置。

| 文件 | 职责 | 行数 |
|---|---|---|
| `hifly-extra.js` | 5 个辅助与作品管理端点（全免费） | 292 |
| `hifly-create-modes.js` | 6 个创作模式端点（全收费） | 354 |
| `hifly.js` | 只加 2 行 `Object.assign` 挂载 | 465 → 469 |

挂载方式与 `hifly-clone.js` 同型（prototype mixin）：

```js
Object.assign(HiFlyAdapter.prototype, require('./hifly-extra').extraMethods)
Object.assign(HiFlyAdapter.prototype, require('./hifly-create-modes').createModeMethods)
```

### 2.2 `KNOWN_METHODS` 登记

`_base/base.js` 的 `KNOWN_METHODS` 是 `callAdapter` 的闸门——不在表里的方法即便子类实现了也**永远调不到**。已登记 11 个（分组注释说明来源与免费/收费）。

**实证**：实跑 `supports()` 逐个核对，11/11 全为 `true`，`capabilities()` 共 22 项。
> 不把「注释写着已登记」当事实——本仓曾因只读注释而误判过一次。

## 三、逐个端点的契约与校验

### 3.1 `getAccountCredit()` — 查询账户积分

**契约**：`GET /account/credit`，响应 `{ code, message, left, request_id }`——**没有 `data` 包裹**，`left` 直接在顶层。
**真实核对**：`{ code: 0, left: 1582 }`。

| 数据校验 | 规则 | 为什么 |
|---|---|---|
| `left` 必须存在 | 缺失 ⇒ `PROVIDER_ERROR` | 前端用它决定「还能不能生成」；兜底成 0 会显示「没积分了」，把接口异常伪装成余额耗尽 |
| `left` 必须非负整数 | 负数/小数 ⇒ `PROVIDER_ERROR` | 积分是整数；脏读数不可信 |

**返回**：`{ left: number }`

**交互逻辑（UI 侧待接）**：
- 进入创作页时拉一次，显示在提交按钮附近（如「剩余 1582 积分」）
- 每次生成成功后**重新拉取**（不本地自减——并发任务会让本地推算失真）
- 拉取失败**不阻塞**创作，只把余额区显示为「—」并保留一个静默重试

**显示项**：`剩余 {left} 积分`
**提示文字**：
- 余额偏低（< 100）：「积分不足 100，生成较长视频可能失败」
- 余额为 0：「积分已用完，请前往飞影控制台充值」
- 拉取失败：「暂时无法读取积分余额」

### 3.2 `listLivelyTemplates(params)` — 查询网感模板列表

**契约**：`GET /video/lively_templates`，免费。

| 参数 | 官方约束 | 本地校验 |
|---|---|---|
| `template` | 指定单个模板 | trim，空则不发 |
| `tag` | 标签筛选 | trim，空则不发 |
| `title` | 标题模糊 | trim，空则不发 |
| `page` | 默认 1 | 必须 ≥1 整数 |
| `size` | 默认 20，**最大 200** | 1~200 整数 |
| `type` | 0 竖屏（默认）/1 横屏/2 方形/3 原始比例 | 必须 ∈ {0,1,2,3} |

**返回**：`{ templates: any[] }`
**关键校验**：`data` 非数组 ⇒ `PROVIDER_ERROR`。
> 不返回 `[]`——空列表会被 UI 读成「平台没有模板」，而那是一次解析失败被伪装成业务结论。

**交互逻辑（UI 侧待接）**：
- 选择「网感模板」模式时按 `type`（画面方向）筛选加载，默认竖屏
- 模板卡片显示：封面图、标题、标签、时长
- 分页：滚到底加载下一页（`size=20`）
- 切换 `type` 时重置到第 1 页

**显示项**：模板封面图、模板标题、标签 chip、时长
**提示文字**：
- 空列表：「当前方向暂无可用模板，试试切换横竖屏」
- 加载失败：「模板加载失败，点击重试」

### 3.4 `createCover(params)` — 创建封面

**契约**：`POST /project/covers`，**免费**。

| 参数 | 官方约束 | 本地校验 |
|---|---|---|
| `template` | **必填** | 非空字符串 |
| `avatar` | 可选（替换封面里的数字人形象） | trim，空则不发 |
| `content` | 与 `slots` **至少一项** | trim |
| `slots` | 与 `content` 至少一项；元素含 `name`/`label`/`value`/`max_length`/`min_length` | 非空数组才发 |
| `canvasPreset` | 9:16（默认）/ 3:4 | 必须 ∈ {`9:16`,`3:4`} |
| `outputFormat` | jpg（默认）/ png | 必须 ∈ {`jpg`,`png`} |

**返回**：`{ coverUrl: string, raw: any }`
**关键校验**：响应里取不到封面地址 ⇒ `PROVIDER_ERROR`。
> 不返回空串——空地址会让 UI 显示一个裂图，比明确报错更难排查。

> **未真实核对**：封面地址的字段名（`cover_url` / `coverUrl` / `url`）在本轮未调用真实接口确认，代码里按常见命名依次兜底；若三者都取不到会报错，届时按真实响应补一次即可。

**交互逻辑（UI 侧待接）**：
- 选模板 → 填文案（或逐槽填值）→ 选画布比例与格式 → 生成 → 预览 → 保存到本地
- `content` 与 `slots` 二选一：给 `content` 时服务端自动填槽；给 `slots` 时精确控制

**提示文字**：
- 两者都不填：「请填写文案，或逐项填写模板槽位」
- 生成中：「正在生成封面…」
- 生成成功：「封面已生成」

### 3.5 `deleteWork(taskId)` — 删除作品

**契约**：`DELETE /video/task?task_id=...`，免费。

| 数据校验 | 规则 |
|---|---|
| `taskId` | 非空字符串（trim 后） |

**返回**：`{ ok: true }`

**关键产品约束（官方原文）**：**仅支持普通视频创作任务 ID**，不支持视频翻译 / 唱歌 / 图片驱动返回的任务 ID。

**adapter 侧无法本地判定任务来源**（不记录任务类型），所以：
- 服务端会拒，`PROVIDER_ERROR` 原文透出（如「该任务不支持删除」）
- **UI 必须只对「普通视频创作」的作品显示删除入口**——这条是 UI 的责任，不是 adapter 的

**交互逻辑（UI 侧待接）**：
- 作品列表里对 `video/create_by_tts` 产生的作品显示「删除」
- 点击弹二次确认：「删除后不可恢复，确定删除《{title}》？」
- 删除成功：从列表移除 + toast「已删除」
- 删除失败：toast 服务端原文（如「该任务不支持删除」）

### 3.6 `createVideoByAudio(params)` — 视频创作（声音驱动）

**契约**：`POST /video/create_by_audio`，**收费**。

| 参数 | 官方约束 | 本地校验 |
|---|---|---|
| `audioUrl` | 与 `fileId` 二选一必填；mp3/m4a/wav，100M 内，5 秒~30 分钟 | trim |
| `fileId` | 与 `audioUrl` 二选一必填 | ≤500 字符 |
| `avatar` | 与 `videoFileId` **至少一个** | trim |
| `videoFileId` | 与 `avatar` 至少一个（可驱动任意视频） | ≤500 字符 |
| `title` | 默认「未命名」，**≤20 字** | 长度校验 |
| `aigcFlag` | 0 跟随设置 / 1 开启 / 2 关闭 | ∈ {0,1,2} |
| `videoStartMsec` | 从指定毫秒开始驱动 | ≥0 整数 |

**返回**：`{ taskId: string }`

**功能逻辑**：上传本地音频 → `ensureFileId` 换 `file_id` → `createVideoByAudio` → 轮询 `getVideoStatus`。

**交互逻辑**：
- 模式选择「声音驱动」→ 选音频文件（或给 URL）→ 选数字人（或上传视频）→ 填标题 → 生成
- 提交前必须显示**收费提示**（见 §4）

**提示文字**：
- 未选音频：「请选择一段音频（mp3 / m4a / wav，5 秒 ~ 30 分钟，100MB 以内）」
- 未选形象：「请选择数字人，或上传一段视频」
- 生成中：「正在生成，通常需要 1~5 分钟」

### 3.7 `createVideoByTemplate(params)` — 视频创作（网感模板）

**契约**：`POST /video/create_by_template`，**收费**。

| 参数 | 官方约束 | 本地校验 |
|---|---|---|
| `template` | **必填** | 非空 |
| `text` | **必填**，≤10000 字，不支持 html | 长度校验 |
| `voice` / `avatar` | **不传 `videoFileId` 时都必填** | 二者与 videoFileId 的联合校验 |
| `videoFileId` | 可替代 voice 与 avatar | ≤500 字符 |
| `title` | ≤20 字 | 长度校验 |
| `bgmFileId` / `ambienceFileId` / `coverFileId` | 可选，≤500 字符 | 长度校验 |
| `normLufs` / `bgmNormLufs` / `audioAssetsNormLufs` / `ambienceNormLufs` | 0~100，不传或 0 表示不指定 | 范围校验 |
| `aigcFlag` | ∈ {0,1,2} | 枚举校验 |

**返回**：`{ taskId: string }`

**关键校验（联合约束）**：`voice` 与 `avatar` 的必填性**取决于** `videoFileId` 是否给出。这是唯一一个「必填性有条件」的参数组，测试里专门锁了「只给 videoFileId + text + template 也合法」。

**交互逻辑**：
- 选模板 → 填文案 → 选音色与形象（或上传视频）→ 可选填 BGM/环境音/封面 → 生成
- 响度归一化是高级选项，默认收起，展开后显示 4 个滑杆（0~100）

**提示文字**：
- 未选模板：「请先选择一个网感模板」
- 未填文案：「文案不能为空（最多 10000 字）」
- 响度说明：「不填或填 0 表示不指定，由服务端自动处理」

## 四、收费提示（跨端点的统一规则）

6 个创作端点收费，且**额度文档未给**。因此：

| 规则 | 说明 |
|---|---|
| **提交前必须提示** | 生成按钮旁固定显示「此操作将消耗积分」，不要只在首次提示 |
| **不本地预估额度** | 官方未给单价，本地算不出来；不做「预计消耗 X 积分」这种假精度 |
| **余额不足时前置拦截** | 提交前若已知 `left` 且 `left <= 0`，直接禁用按钮并提示，不发请求 |
| **失败不自动重试** | 收费端点失败后**不**自动重试（重试可能重复计费），必须用户手动再点 |

## 五、未实现与边界

### 5.1 消息回调（唯一不做的一项）

官方「消息回调」是**服务端推送到你提供的 HTTP 端点**，不是客户端调用接口。本应用是桌面客户端、没有公网回调地址，且当前用**轮询**（`getVideoStatus`）已能拿到任务结果。

**结论：不实现，理由记录在此**，避免下次盘点时又被当成「漏了一个」。

### 5.2 未真实调用的端点

| 端点 | 状态 |
|---|---|
| `account/credit` | ✅ 真实调用过（`left: 1582`） |
| 其余 10 个 | ⚠️ 只按官方文档实现，**未花积分做真实调用** |

原因：6 个创作端点都收费，且额度未知；3 个查询端点依赖真实模板 id（需要先调创作类接口）。**这是本轮已知的验证缺口**，PR 正文会如实写明。

### 5.3 `deleteWork` 的 UI 责任

adapter 无法判定任务来源，所以「只对普通视频创作任务显示删除入口」这条**必须由 UI 落地**，否则用户点到一个必然失败的按钮。

## 七、本轮范围边界（明确不做）

| 项 | 理由 |
|---|---|
| **UI 入口** | 11 个端点的界面工作量 = 6 个新创作模式面板 + 3 个选择器 + 作品管理页，远大于 adapter 层。本轮先把能力接通并锁死契约，UI 作为下一轮独立交付 |
| IPC / preload / renderer API | 同上——需要先定 UI 形态，否则会做出用不上的通道 |
| 真实调用验证 | 6 个端点收费、额度未知，不在未经用户确认前消耗积分 |

> 也就是说：**本轮交付「可用但还没有界面」的能力**。任何 UI 接上后都能直接调通，契约已锁。

## 八、决策记录

| 决策 | 理由 | 备选方案（未选） |
|---|---|---|
| 拆两个新文件而非塞进 `hifly.js` | `hifly.js` 465 行，硬线 500 | 上调 max-lines 基线（会让「点名还账」失效） |
| `data` 非数组时报错而非返回 `[]` | 空列表会被读成业务结论 | 返回 `[]`（曾导致「没有模板」误判） |
| `createCover` 不本地预校验 `content` 长度 | 官方只给 ≤10000 且是**可变文案**，本地按字数拦会误伤带格式的输入 | 同 text 一样卡 10000（本轮未做，留 UI 侧） |
| `deleteWork` 不记录任务来源 | 需引入任务类型表，超出本轮范围 | 本地维护 taskId→类型映射 |
| 收费端点失败不自动重试 | 重试可能重复计费 | 自动重试 1 次（风险不可接受） |
