## 批次 B1：RPA 反检测与验证码（第 1-2 周）

> worktree：`mp-oss-rpa-hardening`。PRD：`01-docs/PRD-OSS-RPA-HARDENING-2026-10-XX.md`

### F1：RPA 窗口 stealth + 行为拟人（三层）— R1-a/b/c（2026-10-13 CCG 评审修订版）

**F1-c：evasions 主世界 document_start 注入**（H1 修订：原 preload 直接注入方案经 Electron 语义实证不成立）
- **被证伪的旧前提**：`rpa-view-session.js:169` 为 `contextIsolation:true + sandbox:true`，preload 运行在独立 JS context——`stealth-preload.js` 内 `Object.defineProperty(navigator,'webdriver')` 等 patch 改的是**隔离世界的 navigator，对页面主世界无感**（该文件头注「等价 Playwright addInitScript」为错误声明，同 PR 修正）。social-auto-upload 的 `add_init_script` 是 Playwright 主世界注入，与本仓 preload 不可类比
- **修正后通道**：`webContents.debugger` + **`Page.addScriptToEvaluateOnNewDocument`**（document_start、main world）——本仓 `webview-manager/utils.js:143` 已有同款实现与回归锁（`webview-manager-ls-document-start.test.js`），复用其「Page 目标就绪等待」基建（`webview-manager/constants.js:25`：Page 目标未建立时 addScript 永久挂起）
- **F2 spike 并入验证项**：①RPA 窗口 debugger attach 时机（`rpa-view-helpers.js:283` 现为上传时 attach，需评估导航前常驻 attach 生命周期与 detach 清理）②sandbox preload 是否暴露 `webFrame.executeJavaScript` 降级路径（未验证前不断言）③注入失败回退纯 Electron 通道并 warn
- **PRD 契约三要素（必含）**：注入了什么（evasion 清单）+ 何时注入（document_start，页面脚本前）+ 失败降级（通道级 warn，发布不中断）
- **kill-switch（M7）**：平台→evasion 子集映射表，可一键关闭单平台注入；某平台被 evasions 反噬时可快速停
- **测试**：行为锁（假 debugger 断言 `Page.addScriptToEvaluateOnNewDocument` 导航前调用且 source 非空）+ 结构锁（npm 包版本锁定 + 提取脚本 sha256 + 产物快照 hash 三重锁，M6——不直接比对 180KB blob）
- **风险登记（H2）**：minified init script 内容 hash 可枚举——本报告 2.1 引 patchright 论证「init script 自身是检测面」同样适用本方案；缓解三选一进 PRD 风险节：①按平台拆分子集注入 ②会话级随机化注入顺序破坏 hash 稳定性 ③取证目标平台未使用该判据后记录豁免

**F1-a：真人事件序列**
- **移植源**：social-auto-upload `_native_click`（源码实证）：scroll_into_view → bounding_box → mouse.move → sleep(150ms) → mouse.click → sleep(200ms) → evaluate 补派 pointerover/enter/down/up + mouse 全套（9 字段）
- **H3 修订——先定义传输无关行为层接口**，Electron/CDP 与 camofox 双实现共用：
  ```
  dispatch(kind: 'move'|'down'|'up'|'click'|'wheel', x, y, opts)   // 纯 CDP Input 域词汇
  getBounds(target)     // CDP DOM.getBoxModel（Electron）/ camofox CDP 同名
  typeText(text)        // CDP Input.insertText / dispatchKeyEvent
  ```
  - `cdp-input.js`：Electron debugger 通道实现（包 `Input.dispatchMouseEvent` + `DOM.getBoxModel`）
  - camofox CDP-WebSocket client 复用同一接口（评审证伪「API 同名零改」预期，L3 已同步）
- **落点**：rpa 平台点击路径（`rpa-view-session.js` `_click`）改调行为层
- **测试**：RED 锁在**接口层**（假 driver 断言事件顺序与间隔±50ms、9 字段完整、无 bounding_box 降级为普通 dispatch）；实现层各锁各的——杜绝「在错误抽象上锁行为」
- **真机取证（L1 修订）**：由「可选」升为「必须」，纳入 B1 数据口径契约（见下）

**F1-b：贝塞尔鼠标轨迹**

### F2：CDP 边信道收敛 — R2（patchright 思路）

**前置 spike（0.5 天，先做；M1 修订：三条候选路径全部列为验证对象）**：
- 路径 A：preload `webFrame.executeJavaScript` —— 需先确认 sandbox preload 子集是否暴露 webFrame（未验证前不断言），且走 IPC 转发链
- 路径 B：主进程 `webContents.debugger` → CDP `Runtime.evaluate` 显式指定 `contextId`（utility context）——patchright utilityContext 的 CDP 等价物，与 F1-c 的 debugger 常驻 attach 同基建
- 路径 C：`Page.addScriptToEvaluateOnNewDocument` 同通道 + utility context 目标（与 F1-c 合并设计）

- **主实现**：`rpa-view-session.js` 的 `executeJavaScript` 调用点评估迁移 isolated 执行。**实证路径仅两条**（FIND-6 修订：主进程不存在「webContents.executeJavaScript + isolated world API」组合）：①CDP `Page.createIsolatedWorld` + `Runtime.evaluateInWorld`（debugger 通道，与 F1-c 同基座）②preload `webFrame.executeJavaScriptInIsolatedWorld` 中继（renderer 侧可用，走 IPC 转发链）；评估 `exposeBinding` 留痕（patchright browserContextPatch 同点）
- **测试**：RED——结构锁（源码断言无裸 executeJavaScript 主世界调用残留）+ 行为锁（假 webContents 断言走 isolated API）；GREEN；真机取证：发布导航期间 main world 无自动化脚本痕迹

### B1 数据口径契约（H4 修订——「数据驱动启停」的可证伪定义）

B1 灰度判定（决策 5 的启停依据）必须满足以下口径，否则不得作为启停证据：

| 项 | 定义 |
|----|------|
| 主指标 | `风控拦截率 = 风控拦截事件数 / 发布尝试数`（拦截=出现风控页/验证码/发布失败且原因归类为风控） |

| 落点 | B1 PRD 验收节 + `openspec/records/<branch>.md` 记录原始计数表 |

### F11：协议轨 TLS 指纹 impersonation — v3 新增（G2-b）

- **组件**：`impers`（lexiforest，MIT，TS，Node 版 curl-impersonation）主选；`curl_cffi`（MIT，Python）作 python-backend 侧备选
- **背景**：百家号/头条/B站 HTTP API 风控查 JA3 TLS 指纹——Node 原生 https 的 ClientHello 与 Chrome 迥异，协议轨 API 发布被 403 时 JS 层伪装无效
- **落点**：`packages/api-publish-engine` 传输层按平台切换 impersonating client（仅风控平台开启，普通平台走原生，控制新增原生依赖面）
- **测试**：RED——传输层选择锁（平台→client 映射、缺省原生）+ 真实 TLS 指纹断言（本机回显服务抓 ClientHello 特征，按项目「出站行为以线级取证为准」纪律）；GREEN
- **红线**：libcurl 原生二进制进生产依赖闭包——`npm pack --dry-run` + 隔离安装加载验证（项目「生产依赖闭包」纪律）；体积预算写 PRD
- **附注**：`ylcangel/douyin_sign`（Apache-2.0）抖音 web a_bogus/x-bogus/msToken 算法——仅当未来加抖音协议轨时启用，需单独 PRD + 风险标注

### F12：视频下载通道（yt-dlp + BBDown）— v3 新增（G6 配套）

- **组件**：**yt-dlp**（197k⭐，**Unlicense 公有领域**——最宽松档，可放心捆绑）+ **BBDown**（MIT，B站专用备份）
- **落点**：按 media-tools 同范式进 `extraResources`（版本+sha256 锁定，QM-1 媒体工具纪律）；消费方：①collection-engine 视频 URL 素材采集；②F10 回流时下载自有作品做存活自证；③story2video 素材来源
- **测试**：RED——下载器封装（URL 白名单/大小上限/取消）+ 结构锁（lock 文件条目）；GREEN；真机：B站/百家号各下 1 条
- **红线**：仅下载有权限的内容（本人作品/已授权素材），频控遵守既有 RateLimiter；不作批量爬取他用
- **附注**：RSSHub（46.5k AGPL）——hot-topics/content-intelligence 的内容源增强。**AGPL-3.0 已于 2026-10-13 复核 LICENSE 原文确认（master 分支 = GNU AGPL v3）**：仅限未修改独立服务直跑；若向产品客户供数据，另按 AGPL 网络交互面评审后决定；node-ytdl-core 停更不选

### F13：自建代理池 — v3 新增（G7）

- **组件**：jhao104/proxy_pool（23.8k，MIT）
- **背景**：同 IP 高频发布多账号是平台风控的核心判据（G7）——camofox 内置代理轮换之外，自持代理池应对重度场景
- **落点**：部署层组件（ops-center/docker-compose 或用户自填代理列表），Electron 侧仅消费「代理列表 API」；**不做进安装包**
- **测试**：RED——消费侧（代理列表获取/失效剔除/按任务分配/失败重试）；GREEN
- **红线**：代理来源合规性由用户自持（工具不内置获取渠道，仅对接用户自有或合规供应商）；PRD 明示边界
- **抓取器默认关（FIND-8 升级为硬编码默认值，非配置项）**：proxy_pool 自带免费代理爬虫**代码级默认关闭**——免费代理是平台风控黑名单高发源（反而放大 G7 要解决的判据），节点被攻陷/涉非法活动时数据泄露责任由产品与用户共同承担；仅对接用户自有/合规供应商 API，UI 明示节点风险
