### Findings

1. **Warning | 决策2**：论据①「桌面不背 Python 依赖」被项目架构否证（python-backend/FastAPI + python-bridge 已随安装自动装 Python 3.12+ 及依赖），优先理由塌了一角。修复：将「faster-whisper 不做」改为「whisper.cpp 默认 + faster-whisper 可选 sidecar」；**但须记 GPU 原生闭包成本账——python-bridge 存在 ≠ GPU 加速免费，faster-whisper 的 CTranslate2/cuBLAS/cuDNN 是额外原生库，不能以「走现有基建」一笔带过**。
2. **Warning | 决策4+S2**：触发条件只写「校验 JA3→升级」与「不触发」，网关行为随端点而异的「无定论」无归口。修复：补第三条路——无定论→不集成，但将 F11 标记低优先级监控项，设「出现真实 403 且定位 TLS」为再探针触发，并保留 TLS 暴露面基线。
3. **Warning | 决策2**：「零 findings」是受审不均衡（决策 1/3/5 有 finding 并被审，决策 2 未深审）的产物，并非结论正确性的证据。修复：显式标记决策 2 为低置信/侧重审，用 A/B 触发条款重评 faster-whisper，勿把零命中当已收敛结论。
4. **Warning | 决策3**：Kokoro-82M 仅凭 Apache 许可入选，缺质量验收门槛（许可合规≠体验达标）。修复：加 A/B 验收：MOS/中文表现/延迟，不达标则前置启动 SoVITS 评估；许可只解决「能不能」，需另立「好不好」。
5. **Warning | 决策1**：license 结论依赖「camofox-browser 确为 MIT wrapper + MPL Firefox 二进制」这一外部断言，若项目不可公开核验或表述不符则结论失效。修复：将该项目 license/来源列为一等可验证证据；补 MPL 未自分发（postinstall 下载）场景下源码互惠义务的边界说明。
6. **Warning | 决策1**：触发「拦截率不低于 Electron 加固通道」缺计量口径。修复：用 A/B 口径（同端点、同负载、同 UA），与决策 5 已加的风控拦截率口径契约对齐。
7. **Warning | 决策5**：「B1 拆两 PR→评审面减半」逻辑失配——拆 PR 降低单次评审量但不降低总 review 行数，反而增工作开销。修复：将该理由改为「降低单 PR 风险面、便于回退、分段合并」，撤掉「减半」表述。
