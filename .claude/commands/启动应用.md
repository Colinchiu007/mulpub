# 启动应用

用当前项目最新代码 + 共享数据（shared-user-data 锚点）启动/重启 Multi-Publish 桌面应用。
支持 Windows 与 WSL（Ubuntu-E）双环境，**默认启动 Windows 环境的应用**。

> **本文件是 Claude Code 的轻量入口。完整定义见 `.agents/skills/start-app/SKILL.md`（单一事实源）。**
> 逻辑修改请改单一事实源，不要在本文件维护重复逻辑。

## 先判定环境（默认 Windows）

```bash
uname -s   # Linux → WSL；MINGW/CYGWIN/MSYS → Windows
```

| 判定 | 启动方式 |
|------|---------|
| **Windows（默认）** | `pwsh -File scripts/start-desktop.ps1 ...` |
| **WSL** | `bash scripts/start-desktop-wsl.sh` |

用户显式说「WSL 启动」→ 走 WSL；否则默认 Windows。

## 再判断应用是否在运行

```bash
ps aux | grep electron | grep -v grep    # WSL
Get-Process electron                     # Windows
```

- **未运行** → 走下方「启动流程」。
- **已在运行 + 用户说「重启」** → 直接执行下方命令（脚本自动停旧实例再起新的）。
- **已在运行 + 用户只说「启动」** → **先询问**是否要重启，避免丢失会话状态。
- **用户只问「在跑吗」** → 只报告状态，不执行停止/启动。

## 启动流程

1. **同步最新（防旧代码启动）**：`git fetch origin` + 核对 `HEAD...origin/main` 落后数。
   - **仅落后** → `git merge --ff-only origin/main`
   - **分叉（本地领先 + 落后）** → ⚠️ `--ff-only` 必然失败，**必须**用 `git merge origin/main`
   - **合并后验证落后数必须为 0**，否则停止不启动（避免用旧代码）
   - ⚠️ **共享主工作区脏文件 > 0 或依赖残缺时**：**绝不在共享主工作区做 git 写操作**或 `pnpm install`（极慢，>1 小时），改用**隔离 worktree** 启动。详见单一事实源「0a/0b」。
2. **Windows 启动（默认）**：
   ```powershell
   pwsh -File scripts/start-desktop.ps1 -Worktree <工作区> -Profile 'D:\tmp\Multi-Publish-debug-profile' -CheckIdentity -Json
   ```
   - 端口被无关 Chrome 占用（9222）时：`$env:MP_VITE_PORT="5175"; $env:MP_CDP_PORT="9224"` 覆盖。
   - **重启时一律加 `-StopForeignProfile`**（其他 worktree 可能留有旧 Electron 进程占用 profile）。
3. **WSL 启动（显式指定时）**：
   ```bash
   bash /mnt/d/Data/projects/mulpub/scripts/start-desktop-wsl.sh
   ```
   - 依赖 Linux 依赖树 `~/mp-wsl-deps/mp-wsl` + 持久库 `~/mp-wsl-deps/electron-libs`
   - 共享 userData 由脚本显式传 `--user-data-dir` 指向 `shared-user-data`
   - 端口被占用时：`MP_VITE_PORT=5175 MP_CDP_PORT=9224` 覆盖
4. **验证**：窗口出现（WSL 看 CDP `/json/list`，Windows 看窗口 handle）+ identity 登录态。

完整流程、失败处理、Pitfalls 见 `.agents/skills/start-app/SKILL.md`。
